# 伏笔：黑日棺与卡西安（卷一主线真相）

## 真相 / 灵感内核

- 长庚塔七层之下封着一口立着的黑石棺：**黑日棺**。棺面刻满名字——被它吞过的名字。它靠「名字」安睡，隔很久要喂一次（上一次是十三年前：「玛丽安·维德」）。
- 棺与「沉日旧教」有关（传说先于太阳的黑暗崇拜；神权纪被灭的旧教之一）。黑日棺苏醒时：太阳变暗、钟声停摆、影子失序、梦境互渗。
- **巡游学院的航线不是随机的**：学院沿内海绕圈，是为了让黑日棺永远待在「有钟声的地方」。无钟之域（旧海图上标着「此段无钟」）是棺唯一能醒到「可以被重封」的位置。
- 老院长伊格纳茨知道一部分；奥菲莉娅知道全部——二十年前那次封印，是她动的手。
- 卡西安：表面是守钟人，实则被低语侵蚀多年。他的女儿玛丽安二十年前死于封印事故（她听见了棺里的声音，主动走进去了）。卡西安引学院入无钟之域，一半是为了重封，一半是他开始相信女儿还在棺里等他。

## 可能的用法

- 卷一铺设意象：灰烬、串梦、塔钟、井与名字（沉钟城古钟支线同源）
- 卷一中后段逐层揭露，幕 E 决战，卡西安以「自己的名字」换「女儿的名字」出棺，人消失在钟声里
- 奥菲莉娅重封，付出记忆代价：她忘了卡西安（二十年前她也忘过玛丽安——她「不再开始」的根源之一，卷二深挖）
- 断钟锤细节：沉钟城老钟匠攥着下葬的断钟锤，事后出现在卡西安的钟室（两座钟、一口井，旧教遗迹网络，卷二海图线）
