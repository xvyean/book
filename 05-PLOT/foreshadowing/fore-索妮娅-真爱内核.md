# 伏笔：手段是假的，感情是真的

## 真相 / 灵感内核

初遇是策划的，入学是计划的延续，暗流操作是持续的——但对伊利安的感情是真实的。这是读者同情她的支点，也是她最终"不再为爱的不纯粹感到羞耻"这一完成态的基础。
