# 伏笔：小灵对伊瑟拉印记的本能感应

## 真相 / 灵感内核

伊利安身边那只林风精灵（小精灵种·林风精灵，五岁小孩心智）对他胸口——也就是伊瑟拉神选印记所在位置——有本能异常反应：有时特别亲近地凑过去蹭，有时突然毛骨悚然般打个哆嗦，然后又凑回来。

它自己并不理解为什么，只是本能。自然灵对"非自然起源的神明烙印"有原始的感知层反应——既被神性温度吸引，又被某种说不清的"异质"警觉。

**核心暗示**：正是这种"神选印记对自然灵的吸引"导致了它当初被伊利安自然吸引而契约——这条链条要等真相揭露时读者才能串起。
