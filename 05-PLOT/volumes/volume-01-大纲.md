# 第一卷《长庚塔下》大纲

**范围**：离开精灵林地 → 巡游学院第一学年结束（约百章，17–20 万字）。
**基调**：七分日常喜剧，两分冒险，一分沉下去的暗。暗色只在卷尾事件里完整露面。

## 已确认事实（正史）

- 伊利安在赴学院途中救下索妮娅（表象）；她留下「我一定会再见到你」。
- 伊利安自精灵林地出发，目的地是停靠在沉钟城的巡游学院。
- 义姐诺蕾莉安比他早一年入学，已是二年级学姐。
- 猫娘菲拉以「感应生」（特殊天赋编入生）身份同期入学，与伊利安同班。
- 奥菲莉娅以藏书院顾问身份开「黄昏课」，伊利安入选（原因与阿拾/魔典异象有关）。
- 借名礼上，伊利安的魔典自行吐出一张无名幻兽卡——白狼阿拾由此登场（卷一谜面）。
- 卷末事件：**低阳事故**（塔底黑日棺苏醒，太阳变暗三日），老钟楼守卡西安的执念收束；奥菲莉娅重封黑日棺并付出记忆代价；卡西安消失在钟声里。

## 感情线（本卷可走到哪）

- **诺蕾莉安**：重逢嘴硬 → 关键退后事件（约 ch30 前后）→ 笨拙和好 → 事故中半句坦白被打断。本卷不到「在一起」，只到「她终于不用话赶话伤人」。
- **菲拉**：始终直球无纠结；本卷只埋「她闻得到他藏着事」的种子，不触发转折。
- **奥菲莉娅**：从「对新生没兴趣」到「这个人和他的狼有点意思」；黄昏课与塔底旧事的裂缝；卷末付出记忆代价，记得阿拾蹭她的温度，不记得卡西安的名字。
- **索妮娅**：双层叙事正式运作——读者从她登场后的秘密单章里知道一半真相；她与伊利安的关系停在「报恩的朋友」，但她自己的心动开始脱离计划（她自己还没察觉）。

## 伏笔铺设（详见 foreshadowing/）

- 阿拾来历（守棺狼血脉 · 二十年前塔底旧事）→ 卷一只露「奥菲莉娅反常地认识它」
- 黑日棺与沉日旧教 → 卷一中后段只给意象（灰烬、梦、无钟之域）
- 诺蕾对索妮娅的直觉对峙 → 本卷只到「第一次皱眉」
- 第十二道门 = 长庚塔（全书级）→ 本卷零提示，仅海图钩子
- 卡西安之女玛丽安 → 卷尾半露，姓名留待卷二

## 卷尾状态（检查清单）

- [ ] 所有登场角色的关系「基准音」立住且彼此不同
- [ ] 阿拾身世钩子生效（读者想查案）
- [ ] 奥菲莉娅「忘记」的谜成立（她记得阿拾，忘了卡西安）
- [ ] 索妮娅的双层叙事让读者既心疼又起鸡皮疙瘩
- [ ] 诺蕾的刺已经拔掉一半
- [ ] 低阳事故的情绪落点：哀而不伤，阳光照常升起，食堂阿姨照常嫌弃
- [ ] 卷二钩子：放假时伊利安在藏书院旧海图上看到一条不该存在的航线
