# 灵感池索引

> [!warning] 使用边界
> 本文件夹只放可替换灵感。所有新条目必须满足 [[01b-网文风格契约|网文风格契约]] 的禁忌、必备元素与字数下限。任何条目进入正文或正式设定前，都必须经过设定考据（4 号）和总编验收（7 号）。

## 使用规则

- 新灵感默认放进最贴近的分类文件。
- 每条灵感按场景四件套写：标题 + 场景锚 + 正文 + 钩子。
- 场景级 ≥150 字，台词级 ≥50 字。详见 [[01b-网文风格契约#四、字数下限]]。
- 不允许"情感浓度：N"标签——属于禁忌 5。
- 灵感可以互相冲突，冲突不在这里解决，由 [[01-多Agent构想工作流|主笔（1 号）]] 在迭代中归纳。
- 旧 [[ai构想/_废案/2026-04-25-重构-开篇大纲灵感池-废案/00-废案说明|废案]] 只能作为素材矿，不作为当前结构基础。

## 单条灵感模板（场景四件套）

```markdown
### 灵感标题

**场景锚**：（一句给时间地点和触发动作。例："演练场事故第二天，宿舍楼下"）

（场景正文：直接对话流为主，至少 3 轮对话+5 个动作节拍。
穿插破折号思绪、感官细节、动作微观。
不写"她的扭曲点是…"。不写作者点评。
对话占场景文本 ≥40%。字数 ≥150。）

**钩子**：（一句具体物证 / 动作 / 留白收尾。例："书拿倒了。"）
```

### 提交前自检

- [ ] 场景锚一句话内交代时间地点
- [ ] 至少 3 轮直接对话，对话占 ≥40%
- [ ] 末句是物证 / 动作 / 留白，不是分析
- [ ] 没有触发 [[01b-网文风格契约#二、五条硬禁忌|五条禁忌]]
- [ ] 字数达底线
- [ ] 角色行为对得上 [[01b-网文风格契约#六、五人角色行动备忘库|行动备忘库]]
- [ ] 没有"情感浓度：N"标签
