# 灵感池：第一批

## 开篇与旅途

### O-01 希尔不肯进包与自然气味

- 主功能：开篇钩子
- 所属系统：自然妖精 / 神选模糊异常
- 关系对象：希尔
- 适用阶段：开篇
- 强度：轻
- 涉及角色：伊利安、希尔
- 核心冲突：希尔不理解离别，只知道伊利安要去陌生地方。
- 画面/事件：伊利安整理行李，希尔一次次钻进包里；后续第一只幻兽闻到它身上没有血液认主和卡框术式的自然气味，因此本能不安。
- 爽点或情感点：无台词也能写出“被需要”。
- 设定作用：明确希尔是自然妖精，不是幻兽。
- 冲突后果：轻微铺垫离别和后续“自然生命 vs 炼成生命”的对照。
- 风险：不要写成纯卖萌，要接上胸口印记的模糊反应。
- 推荐度：候选

### O-02 玫瑰金的惊光

- 主功能：悬念投放
- 所属系统：神选模糊异常
- 关系对象：希尔
- 适用阶段：开篇
- 强度：中
- 涉及角色：伊利安、希尔
- 核心冲突：自然生命本能感到某种神性不协调。
- 画面/事件：希尔靠近伊利安胸口时突然惊开，光色从青绿变成陌生玫瑰金，又立刻褪回去。
- 爽点或情感点：小细节埋大线。
- 设定作用：铺胸口印记，但不公开定性为伊瑟拉神选。
- 冲突后果：伊利安误以为希尔怕生，读者知道异常存在。
- 风险：不要解释太多，不让印记赋予力量。
- 推荐度：大纲可用

### O-03 旧中继站的第二次相遇

- 主功能：旅途事件
- 所属系统：梦视
- 关系对象：索妮娅
- 适用阶段：开篇
- 强度：中
- 涉及角色：伊利安、索妮娅

- 画面/事件：索妮娅醒来第一句话是“这一次你没有死”，随后立刻改口。
- 爽点或情感点：温柔表层下的梦视裂缝。
- 设定作用：建立索妮娅不是普通被救者。
- 冲突后果：伊利安选择不追问，索妮娅从此获得靠近他的理由。

### O-04 索妮娅笑着占位

- 主功能：关系推进
- 所属系统：梦视 / 学院入口
- 关系对象：索妮娅

## 学院与制度

### A-01 事故复盘课第一句

- 主功能：制度压力
- 所属系统：学院制度 / 幻兽炼成
- 关系对象：群像
- 适用阶段：第一卷前段
- 强度：中
- 涉及角色：伊利安、新生、教授
- 核心冲突：学院想把幻兽纳入课程，事故却证明幻兽不是工具。
- 画面/事件：教授开口不是讲战斗，而是说：“如果你只是想要一张会替你打架的卡，请现在退出这门课。”
- 爽点或情感点：立刻把幻兽和普通召唤物区分开。
- 设定作用：强调幻兽是炼制生命。
- 冲突后果：新生必须签署事故复盘确认，后续违规炼成才有制度后果。
- 风险：不要说教太久，要用事故档案推动。
- 推荐度：大纲可用

- 所属系统：学院制度 / 魔典卡槽

- 画面/事件：精神力粗筛石板短暂显示无法归档的波纹，工作人员改成“一阶，待复核”。远处艾拉拉看到了。
- 爽点或情感点：公开场合里的隐藏异常。
- 设定作用：推进艾拉拉观察线和档案改写暗线。
- 冲突后果：伊利安进入被复核名单，档案改写者有机会下手。
- 风险：不能太像开挂认证。
- 推荐度：大纲可用

### A-03 家族炼成谱系炫耀

- 所属系统：多种族文化 / 幻兽炼成

- 推荐度：候选

- 推荐度：大纲可用

- 所属系统：队伍政治
- 关系对象：群像、第一只幻兽
- 适用阶段：第二卷
- 强度：强
- 涉及角色：四位女主、第一只幻兽、伊利安
- 核心冲突：大家争的不是谁更被喜欢，而是谁有资格在危险时替伊利安做决定。
- 画面/事件：伊利安被要求留在医疗室，幻兽守门，诺蕾莉安拿学姐身份压它，索妮娅微笑绕开规则，菲拉直接蹲在门口，艾拉拉说“无关人员离开”却没点名谁是无关人员。
- 爽点或情感点：争宠升级成保护权争夺。
- 设定作用：把感情线、幻兽自主性和制度压力拧在一起。
- 冲突后果：伊利安必须第一次明确让谁留下。
- 风险：不要写成闹剧，要有伤情或审查背景。
- 推荐度：大纲可用

## 主线危机

### M-01 污染素材不是事故

- 主功能：主线危机
- 所属系统：污染素材 / 副岛门扉
- 关系对象：学院高层
- 适用阶段：第一卷中段
- 强度：强
- 涉及角色：伊利安、艾拉拉、学院高层
- 核心冲突：用于低阶炼成的素材出现高阶污染。
- 画面/事件：素材在伊利安手里稳定，在别人手里发黑，像是在选择容器。
- 爽点或情感点：主线通过炼成进入。
- 设定作用：连接门扉和幻兽。
- 冲突后果：采集窗口被迫提前关闭，学院仍低估风险。
- 风险：别太早抬到世界危机。
- 推荐度：大纲可用

### M-02 梦线被咬断

- 主功能：主线危机
- 所属系统：梦视 / 幻兽关系
- 关系对象：索妮娅、第一只幻兽
- 适用阶段：第二卷
- 强度：强
- 涉及角色：索妮娅、第一只幻兽、伊利安
- 核心冲突：索妮娅试图梦视伊利安的危险，幻兽误判为入侵。
- 画面/事件：梦里她伸手去拉伊利安，卡面里冲出幼兽的影子，一口咬断梦线。
- 爽点或情感点：温柔梦视和护主本能正面撞上。
- 设定作用：梦视不是无痕能力，幻兽有主动边界。
- 冲突后果：索妮娅醒来短暂失声，幻兽也精神萎靡。
- 风险：不能让幻兽伤害女主后无处理。
- 推荐度：候选

### M-03 认主记录噪声

- 主功能：伏笔回收
- 所属系统：血液认主 / 神选模糊异常
- 关系对象：第一只幻兽
- 适用阶段：第一卷卷末
- 强度：强
- 涉及角色：伊利安、第一只幻兽、审查员
- 核心冲突：幻兽认主合法完成，但记录里出现无法解释的法则噪声。
- 画面/事件：成卡瞬间，卡框闪过一圈玫瑰金，复核报告只写“异常光谱，原因待查”。
- 爽点或情感点：开篇希尔反应回收。
- 设定作用：把幻兽线和神选线轻轻扣住。
- 冲突后果：学院开始追查素材和档案，不承认这是神选。
- 风险：不能让神选影响认主、改写结果或把幻兽变神兽。
- 推荐度：大纲可用

### M-04 主人豁免协议

- 主功能：伦理冲突
- 所属系统：学院制度 / 血液认主
- 关系对象：第一只幻兽、学院高层
- 适用阶段：第二卷
- 强度：强
- 涉及角色：伊利安、第一只幻兽、学院审查员
- 核心冲突：学院想用“主人同意”豁免幻兽高风险测试责任，幻兽无法被当作同意书附件。
- 画面/事件：协议上写着主人承担全部后果，幻兽在卡面里把名字位置抓花。
- 爽点或情感点：所有权伦理正面爆发。
- 设定作用：主人不是幻兽的绝对所有者。
- 冲突后果：伊利安拒签，失去一次考核资格。
- 风险：不要让制度脸谱化，协议应有现实管理逻辑。
- 推荐度：候选

### M-05 情绪诱导对战

- 主功能：战斗考核
- 所属系统：幻兽对战 / 学院制度
- 关系对象：第一只幻兽、女主群像
- 适用阶段：第二卷
- 强度：强
- 涉及角色：伊利安、第一只幻兽、菲拉、诺蕾莉安、索妮娅
- 核心冲突：考核故意诱导幻兽嫉妒，测试主人能否稳定队伍。
- 画面/事件：考官安排女主靠近伊利安，观察幻兽是否失控。菲拉当场指出“你们是在惹它，不是在测它”。
- 爽点或情感点：女主直接站出来争。
- 设定作用：幻兽情绪也是战斗风险。
- 冲突后果：幻兽通过一半考核，但伊利安质疑考核伦理。
- 风险：不能把女主当工具人，要让她们有反应和立场。
- 推荐度：大纲可用

### M-06 他人强行召唤失败

- 主功能：制度压力
- 所属系统：血液认主 / 魔典卡槽
- 关系对象：第一只幻兽、学院高层
- 适用阶段：第二卷
- 强度：爆点
- 涉及角色：伊利安、第一只幻兽、审查员或敌对学生
- 核心冲突：他人试图证明幻兽只是卡，强行召唤却触发反噬。
- 画面/事件：对方拿到卡面复核权限，念出召唤式，卡面没有打开，只在他手背烫出拒绝纹。
- 爽点或情感点：规则本身替幻兽和伊利安说“不”。
- 设定作用：确认幻兽不可转让、不可被他人正常使用。
- 冲突后果：听证升级，学院不得不承认幻兽拒绝也有法律意义。
- 风险：不要让敌对者拿到卡显得流程离谱，需要审查或事故背景。
- 推荐度：大纲可用

### M-07 学院隐藏的旧炼成室

- 主功能：主线危机
- 所属系统：学院高层 / 人形幻兽
- 关系对象：艾拉拉、索妮娅
- 适用阶段：第三卷
- 强度：爆点
- 涉及角色：伊利安、索妮娅、艾拉拉
- 核心冲突：学院曾经做过高心智幻兽或人形幻兽实验。
- 画面/事件：旧炼成室墙上不是阵图，而是很多名字。每个名字后面都有卡槽编号。
- 爽点或情感点：日常学院突然变冷。
- 设定作用：铺人形幻兽远期线，第三卷再触及学院封印结构。
- 冲突后果：艾拉拉必须在制度和真相之间做选择。
- 风险：不宜第一卷就完全揭开。
- 推荐度：暂缓

### M-08 魔典容量正常，关系压力异常

- 主功能：悬念投放
- 所属系统：魔典卡槽 / 神选模糊异常
- 关系对象：艾拉拉、学院高层
- 适用阶段：中后期
- 强度：中
- 涉及角色：伊利安、艾拉拉、学院高层
- 核心冲突：学院能记录卡槽、魔力、阶位，却记录不了关系性压力。
- 画面/事件：伊利安的魔典检测显示容量完全正常，没有隐藏空位，但精神回路图上总有一段无法命名的回声。
- 爽点或情感点：系统无法解释主角核心。
- 设定作用：修正“神选空位”风险，神选不绕过容量，只制造检测盲区。
- 冲突后果：高阶者开始怀疑这不是卡槽问题，而是法则关系问题。
- 风险：中后期再用，不能变成额外卡槽。
- 推荐度：暂缓
