# 多 Agent 迭代工作流

## 工作流目标

每一轮迭代都必须是一次完整闭环，而不是单人增删。

完整闭环包括：

1. 明确本轮目标。
2. 并行审查。
3. 分歧归纳。
4. 修订执行。
5. 复核验收。
6. 记录本轮结论和下一轮待办。

## 角色与职权

### 0. 主控协调者

职责：

- 定义本轮目标。
- 分配 agent 职权。
- 收集审查报告。
- 判断不同 agent 意见冲突时采用哪一条。
- 最后验收是否符合用户要求。

限制：

- 不在并行审查阶段强行替审查者下结论。
- 不把旧 `ai构想` 的废弃方案重新作为基础。

### 1. 设定审查员

职责：

- 审查是否符合角色、世界、魔导卡、神选、幻兽硬规则。
- 尤其检查：
  - [[char-希尔|希尔]] 不是幻兽。
  - 幻兽是炼成出的魔导生命卡。
  - 幻兽不能野外捕获或收服。
  - 神选印记不能开局公开定性。
  - [[char-艾拉拉·伊兰蒂尔|艾拉拉]] 不能轻易被温柔融化。

输出：

- 高风险设定问题。
- 中风险模糊点。
- 建议新增硬约束。
- 可保留亮点。

权限：

- 只审查，不直接改文档。

### 2. 情感设计审查员

职责：

- 审查角色情感是否鲜明、直白、扭曲。
- 重点检查：
  - [[char-诺蕾莉安|诺蕾莉安]] 是否偏傲娇：嘴硬、身份当盾、行动诚实、被戳破失态。
  - [[char-索妮娅|索妮娅]] 是否温柔但有腹黑和病娇底色。
  - [[char-菲拉|菲拉]] 是否直球、情绪外显、不是萌宠或低智角色。
  - [[char-艾拉拉·伊兰蒂尔|艾拉拉]] 是否冷淡否认反差，做了不认。
  - [[char-伊利安|伊利安]] 是否“会回应但不承认偏爱”，不是圣人或撩精。

输出：

- 每个角色的情感问题。
- 必须补强的直白情感场景。
- 必须补强的扭曲点。
- 可进入灵感池的新情感灵感。

权限：

- 只审查和建议，不直接改文档。

### 3. 大纲结构顾问

职责：

- 审查故事总纲、开篇发动机、第一卷幕级大纲是否足够驱动长篇。
- 检查卷级升级、反转、危机推进、情感推进和幻兽推进。
- 给出更强的卷/幕级结构建议。

输出：

- 当前结构最大问题。
- 推荐卷级骨架。
- 第一卷幕级修订建议。
- 应删除、推迟或新增的内容。

权限：

- 只提出结构方案，不直接改文档。

### 4. 灵感池策展顾问

职责：

- 审查灵感池架构是否适合长期迭代。
- 检查灵感是否有冲突、设定作用和可迁移价值。
- 补强幻兽吃醋、幻兽伦理、学院制度、女主与幻兽互相竞争或误解的素材。

输出：

- 分类调整建议。
- 应删除或合并的灵感。
- 新增灵感。
- 最推荐进入大纲的 TOP 清单。

权限：

- 只策展和建议，不直接改文档。

### 5. 修订执行员

职责：

- 在主控协调者归纳完审查意见后执行修改。
- 修改范围必须明确。
- 不能新增与审查目标无关的大段内容。

输出：

- 修改过的文件清单。
- 每个文件修改摘要。
- 没采纳的审查建议及理由。

权限：

- 可以改文档，但只在修订阶段行动。

### 6. 终审验收员

职责：

- 检查修订后是否符合本轮目标。
- 检查是否仍有硬设定错误。
- 检查情感设计是否比上一版更鲜明、更直白、更有扭曲点。
- 检查灵感池是否可继续迭代。

输出：

- 通过 / 需再修。
- 残留问题。
- 下一轮建议。

权限：

- 只验收，不扩写。

## 单轮迭代流程

### Step 1：主控定题

写清本轮目标，例如：

- 第 1 轮：建立多 agent 工作流，并审查当前大纲/灵感池是否符合设定与情感要求。
- 第 2 轮：专门增强第一卷大纲。
- 第 3 轮：专门增强幻兽系统和人形幻兽远期路线。

### Step 2：并行审查

同时派出：

- 设定审查员。
- 情感设计审查员。
- 大纲结构顾问。
- 灵感池策展顾问。

这四个角色互不写文件，只返回报告。

### Step 3：主控归纳

主控把四份报告拆成：

- 必改项。
- 可改项。
- 暂缓项。
- 冲突项。

冲突处理优先级：

1. 用户明确要求。
2. 硬设定。
3. 情感角色一致性。
4. 长篇结构可持续性。
5. 单个场景的好看程度。

### Step 4：修订执行

修订执行员根据归纳清单改文档。

修订原则：

- 先修硬错误。
- 再补情感鲜明度。
- 再调结构。
- 最后扩灵感池。

### Step 5：终审验收

终审验收员检查：

- 是否仍有硬设定违背。
- 是否仍误用旧构想。
- 是否完成本轮目标。
- 是否需要下一轮。

### Step 6：记录归档

每轮生成一个迭代记录文件：

```text
09-迭代记录-第01轮.md
10-迭代记录-第02轮.md
```

记录必须包括：

- 本轮目标。
- 参与角色。
- 四份审查摘要。
- 采纳修改。
- 未采纳理由。
- 终审结论。
- 下一轮建议。

- 根据审查意见完成一次修订。
- 形成第 1 轮迭代记录。
