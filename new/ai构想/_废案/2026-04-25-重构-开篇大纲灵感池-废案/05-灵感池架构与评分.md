# 灵感池架构与评分

## 目标

灵感池不是垃圾桶，也不是名场面堆放处。

它要服务三件事：

1. 快速积累画面、冲突、台词和机制。
2. 能筛出可进入大纲的事件。
3. 能反向提醒设定哪里还没被剧情化。

## 灵感条目格式

每条灵感使用多轴标注。不要只写“类型”，因为同一条灵感往往同时承担制度、关系和主线功能。

```markdown
### 编号 标题

- 主功能：
- 所属系统：
- 关系对象：
- 适用阶段：
- 强度：
- 涉及角色：
- 核心冲突：
- 画面/事件：
- 爽点或情感点：
- 设定作用：
- 冲突后果：
- 风险：
- 推荐度：
```

## 多轴标签

### 主功能

用于判断这条灵感主要服务什么。

- `开篇钩子`
- `旅途事件`
- `学院入口`
- `悬念投放`
- `制度压力`
- `关系推进`
- `战斗考核`
- `伦理冲突`
- `主线危机`
- `轻喜剧缓冲`
- `伏笔回收`

### 所属系统

用于判断它绑定哪套设定。

- `学院制度`
- `魔典卡槽`
- `幻兽炼成`
- `血液认主`
- `卡面活化`
- `素材经济`
- `副岛门扉`
- `梦视`
- `神选模糊异常`
- `多种族文化`

### 关系对象

用于判断它推进哪条关系。

- `诺蕾莉安`
- `菲拉`
- `索妮娅`
- `艾拉拉`
- `希尔`
- `第一只幻兽`
- `第二只幻兽`
- `学院高层`
- `群像`
- `无`

### 阶段

- `开篇`
- `第一卷前段`
- `第一卷中段`
- `第一卷卷末`
- `第二卷`
- `第三卷`
- `第四卷以后`
- `暂缓`

### 强度

- `轻`：只提供画面、笑点或小伏笔。
- `中`：能改变一次关系或推进一次制度认知。
- `强`：带来审查、伤害、违规、公开冲突或不可逆选择。
- `爆点`：可作为幕末、卷末或重大转折。

旧的“类型标签”仍可作为副标签写进 `主功能` 或 `所属系统`，但不能替代多轴标注。

## 评分维度

每条灵感按 1-5 分评估。

| 维度 | 问题 |
|------|------|
| 可写性 | 能否直接扩写成场景？ |
| 设定贡献 | 是否让一个设定变得更具体？ |
| 情感张力 | 是否让角色关系发生变化？ |
| 主线推动 | 是否推进神选、学院、门扉或卷目标？ |
| 幻兽贡献 | 是否强化幻兽系统独特性？ |
| 新鲜度 | 是否避开常规套路？ |
| 冲突后果 | 是否带来审查、代价、关系裂痕或制度压力？ |
| 大胆度 | 是否敢触碰所有权伦理、违命、隐私、保护资格争夺等高压题？ |

推荐度规则：

- 33 分以上：优先进入大纲。
- 25-32 分：保留为候选。
- 18-24 分：只保留画面或台词。
- 低于 18 分：删除、合并或重写。

## 状态标记

- `种子`：只有画面或一句话。
- `候选`：可扩写，有明确冲突。
- `大纲可用`：可放入卷纲或幕纲。
- `正文可用`：可直接扩写成正文场景。
- `暂缓`：设定有潜力，但当前阶段不适合。
- `废弃`：不符合硬设定或太套路。

## 迁移规则

灵感进入正式大纲前要过三道门：

1. 是否符合硬设定，尤其是幻兽炼成规则。
2. 是否服务当前卷目标。
3. 是否让至少一个角色关系或主线问题发生变化。

只“好看”的场景不能直接进大纲。它必须让某个东西改变。

## 迁移硬门槛

以下情况不得迁移进正式大纲，必须重写：

- 神选印记赋予力量、创造卡槽、替代炼成流程或直接改写幻兽结果。
- 第一只幻兽不是通过正式炼成、血液收束、自动认主诞生。
- 别人的幻兽服从伊利安、改主或脱离原绑定。
- “家族幻兽”被写成继承幻兽卡本体，而不是炼成记录、配方传统或培育经验。
- “关系卡”“神选空位”绕过魔典容量和卡槽规则。
- 开篇角色公开定性伊利安为伊瑟拉神选。
- 艾拉拉早期快速软化、袒护、心动，越过观察和制度维护阶段。

优先迁移的灵感应当具备至少一项强后果：听证、封存、审查、公开争执、战斗失误、幻兽违命、女主与幻兽争夺保护资格、素材来源公示或血液认主复核。
