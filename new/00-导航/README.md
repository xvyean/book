- `[[02-世界/_index|02-世界]]`：地点、智慧种族、神明、生灵、组织、规则、历史、物品
- `[[03-剧情/_index|03-剧情]]`：总纲、分卷、分幕、伏笔、全局灵感
- `[[04-正文/_index|04-正文]]`：正文章节、场景碎片、废稿

- `[[90-规则/_index|90-规则]]`：建档规则、更新规则、模板规则
