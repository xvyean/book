# 加护卡（Aura / Buff Cards）

## 概述

加护卡是魔导卡体系中的**外挂插件层**，职能是为已召唤的精灵、幻兽或武装赋予额外特性、被动或主动技能。加护卡本身不产生独立效果——它必须依附于另一张已激活的召唤卡/武装卡之上才能生效。这种插件逻辑使卡组构筑的上限极高，是体系中灵活性最强的分类。

> **AI 速读**：加护卡 = 叠加在召唤物身上的"特性标签"。不能单独使用，不能叠加在魔法卡上。叠加数量有阶段限制。最高阶应用是「跨阶过载加护」——以蓝条为代价换取临时爆发力。

---

## 一、核心机制

### 叠加规则

| 规则 | 说明 |
|------|------|
| **合法目标** | 精灵卡召唤物、幻兽卡召唤物、武装卡武装形态 |
| **非法目标** | 魔法卡（绝对禁止，无论任何情况） |
| **叠加方式** | 同时激活多张加护卡叠加于同一目标 |
| **阶位接口** | 低阶加护卡叠加于高阶召唤物上可能产生兼容性问题；高阶加护卡可降阶兼容低阶召唤物，但属于资源浪费 |

### 叠加层数上限（按阶段）

| 魔导师阶段 | 最大叠加层数 |
|-----------|------------|
| 见习阶（1-3阶） | **1层** |
| 升华阶（4-6阶） | **2层** |
| 超凡阶（7-9阶） | **2层（可触发跨阶过载）** |
| 不朽阶（10-12阶） | 理论上限不明，极少有文献记录 |

## 二、典型特性举例

加护卡赋予的特性本质上是"给召唤物贴被动标签"：

| 加护类型 | 叠加对象 | 实际效果 |
|----------|----------|----------|
| **【烈焰卡】** | 精灵/幻兽 | 普攻附加火属性额外伤害，具备简单火球释放能力 |
| **【巨大化卡】** | 精灵/幻兽 | 体型与血量大幅提升，转型为肉盾角色 |
| **【吸血卡】** | 武装（召唤的武器形态） | 攻击命中时回复持有者魔力/体力 |
| **【轻灵卡】** | 武装 | 武装挥击速度极速提升，可打出残影连击 |

## 三、高阶应用：跨阶过载加护

**跨阶过载加护**是加护卡体系中最极端的战术手段。

### 原理

在超凡阶（7阶+）以上，魔导师可以将**超出召唤物正常承载能力**的高阶加护卡强行叠加，以压榨自身魔力回路（蓝条）为代价，换取召唤物**临时爆发出跨阶级别的恐怖破坏力**。

### 代价与风险

- **魔力消耗剧增**：过载期间蓝条以数倍速率燃烧，持续时间极短。
- **召唤物不稳定**：召唤物的术式结构在过载状态下承受巨大压力，有崩溃解体的风险。
- **灵魂承载压力**：对持有幻兽卡的魔导师来说，过载可能波及灵魂绑定，造成反噬。

### 适用场景

- 短时间内需要摧毁远超自身阶位的目标。
- 作为逆转战局的最后手段，不适合常规战斗使用。

---

## 四、规则硬性限制

- 加护卡**绝对不能**单独激活，必须依附于合法目标。
- 加护卡**绝对不能**直接叠加在魔法卡上。
- 叠加层数超出当前阶段上限时，多余的加护卡**不会生效**而是术式冲突（轻则无效，重则引发魔力暴动）。
- 跨阶过载加护在见习阶和升华阶**无法触发**——当前灵魂承载不足以支撑过载状态。
