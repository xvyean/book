# 第二十四章 演练日

风暴演练的告示，是早上贴出来的：午后未时，全城演练。各科按区集合，收帆固物，听钟声行动。

“风暴演练是什么？”菲拉问。

“假的。”科尔抢答，“假装来了一场大风暴，大家练怎么保命。我们学院每个月练一次——我爹说，平时练得勤，真出事才不慌。”

“你爹什么都说过。”

“那是！”科尔骄傲地挺起胸，“我爹是炉坊里话最多的铁匠！”

未时，钟声敲了两下。

演练开始。城头的风灯一齐熄灭，旗杆上的旗降了半截，长桌厅的碗筷收进柜里，各科的教习站在各自的区域，吼着学生往该去的地方跑。

伊利安被分在城头组——负责把垛口边的沙袋码到防风位。他抱着沙袋跑了两趟，回头看见菲拉蹲在灯楼下，正跟孙老头抢一只大铜铃：“孙爷爷！演练呢！您怎么还坐着！”

“演练归演练，灯不能灭！”孙老头护着铜灯，“灯灭了，真船来了怎么办！”

“这是演练！”

“演练也是夜！”孙老头中气十足，“你们演练你们的，我守我的灯——灯楼的天职是灯！”

菲拉争不过他，气鼓鼓地跑走了。孙老头看着她跑远，哼了一声，却伸手把灯芯拨亮了一点。

伊利安码完沙袋，正要往下一个点跑，忽然听见城头东边传来一声闷响——“轰！”

他下意识往墙根一缩。这个声音他熟——炉翼楼方向的炸炉声，他在工读时听了没有十回也有八回。

“……演练呢，谁在炸炉？！”老赫德的吼声从城头传来。

不是炉翼楼。声音是从东头器材库方向来的。伊利安跑过去一看——器材库门口围了一圈人，科尔坐在地上，满脸黑灰，面前散着一堆冒烟的零件。他脚边躺着一张烧焦的卡，卡面上还冒着火星。

“……你，”伊利安蹲下来，“演练的时候，你在器材库炼卡？”

“不是炼卡！”科尔咳嗽了两声，“是保管！器材库的卡要移到防水柜——我搬的时候它自己亮了！它自己炸的！”

“卡不会自己亮。”

“它会！”科尔指着那张焦卡，痛心疾首，“这张是上个月工坊的失败品，我说过要销毁——雷欧说留着还能卖废料！它这是报复！它记仇！”

“……卡记仇这种话，你从哪听来的？”

“菲拉说的！”科尔理直气壮，“她说卡跟刀一样，你不好好待它，它就记仇！”

伊利安张了张嘴，发现这话确实是他听过的——月桂班的术理课上，菲拉睡觉被点名，答的就是这句。老赫德还夸她比讲义讲得好。

“……那也不是你带进演练场的理由。”伊利安把他从地上拽起来，“走，先去医务那边看看有没有烧着。”

“没事！就燎了点头发！”科尔拍着脑袋上的灰，忽然脸色一变，“——等等，我的防水柜！柜子里还有三张卡！”

他拔腿就往器材库跑。伊利安追上去，刚进门，就看见科尔踩到地上的一滩水——那是刚才炸炉泼出来的——脚下一滑，整个人从器材库后门飞了出去。

后门外是城墙。城墙外是海。

“……科尔！”伊利安扑到垛口往下看。

科尔正在海面上扑腾，四肢划得飞快，呛一口水喊一声：“救——咕噜——命——咕噜！”

“别慌！”伊利安解下外袍，“我下来——”

“你下来干什么！”城头传来洛塔的声音。平日慢吞吞的海族少年这会儿快得像一阵风，从垛口翻下去，在城墙上点了一下，扎进海里，水花都没溅起几朵。

伊利安趴在垛口，看着海面。过了大约十几息，洛塔托着科尔浮上来——科尔趴在他肩上，咳得惊天动地，洛塔倒是气定神闲，单手划着水，慢吞吞地往城墙边游。

“……谢、谢谢。”科尔趴在城墙上，吐了两口水，“你、你游得真快。”

“不快。”洛塔扒着城墙，喘匀了气，“风浪大，慢了两拍……是吧。”

“……你管这叫慢？”

“我们海族，这个季节的浪，三息就该上岸了。”洛塔慢吞吞地说，“我用了五息……回去要多练。”

科尔张着嘴，半天没说出话。最后他憋出一句：“……你欠我一次！”

“是你欠我。”洛塔说，“请我吃鱼。”

“……行！三顿！不——一顿！一顿鱼就顶三顿！”

演练结束，钟声敲了三下。

老赫德站在城头，把各组叫过来训话。他先看了科尔一眼：“器材库保管，卡没进防水柜，人先进了海。”

“……是。”科尔耷拉着脑袋，“我错了。”

“错在哪？”

“错在不该带失败品进演练场。”

“错在拿命赌卡。”老赫德说，“卡炸了能再炼，人淹了能再捞吗？”

科尔没敢顶嘴。老赫德又转向洛塔：“海族的水性，今天算见识了。反应快，捞得稳——记一功。”

洛塔慢吞吞地开口：“教习，不用记功……记一条鱼就行。”

人群里响起一片笑声。雷欧已经掏出小羊皮本，唰唰记了两行：“科尔·燃须，欠洛塔救命之恩一次，折合鲜鱼三尾——其中两尾为利息。科尔签字处：____。”

“……雷欧，你是人吗？”

“账目不清，心里不净。”雷欧头也不抬，“签字。”

晚饭后，伊利安抱着阿拾在城头散步。

海风比白天小了些，海面上铺着碎碎的月光。阿拾趴在他怀里，耳朵忽然竖起来，朝海面转了转。

伊利安顺着看过去——海面上，一群海鸥正贴着浪尖飞过。灰白色的，翅膀边缘焦了一圈，像被火燎过，跟他昨天在窗台上看见的那只一模一样。

“又是这种鸟。”他皱了皱眉，“昨天也看见一只。”

“灰鸥。”旁边传来一个声音。老赫德不知什么时候站在了垛口边，手里捏着烟斗，没点，“老的灰鸥是白的。这种灰法，少见。”

“……少见？”

“嗯。”老赫德看着那群鸟飞远，声音平平的，“我上次见这种毛色的灰鸥，还是二十多年前。”

他没再说下去。伊利安想问，他已经转身走了，烟斗在手里转了一圈，始终没点着。

海风灌过来，带着一点说不清的腥味。阿拾趴在伊利安怀里，看着那群灰鸥消失的方向，耳朵垂着，一动没动。

“——回去睡觉了。”伊利安摸了摸它的头，转身往北塔走。

走出两步，他回头看了一眼。

老赫德的身影已经消失在城头的暮色里。只有他站过的垛口边，落着一小撮灰白色的羽毛，在风里打着旋儿。
