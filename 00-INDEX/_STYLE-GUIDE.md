# 写作风格指南

## 设定文件的写作规范

### 结构
1. Frontmatter 必须完整填写（参照模板）
2. 正文第一段为概述（与 summary 呼应但可以更详细）
3. 使用二级标题分节
4. 关键实体使用 `[[wikilink]]`

### 语言风格
- 设定文件使用**简洁客观的百科风格**
- 正文章节使用**口语化网文风格**（详见下文《正文写作风格》）
- 避免在设定文件中使用第一人称

### AI 协作约定
- 创建新文件时，必须同步更新对应的 `_index.md`
- 修改角色关系时，双向更新（A 的 allies 加了 B，B 的 allies 也要加 A）
- 新增设定不得与已有设定矛盾，如有冲突需先讨论

# 正文写作风格

> **一句话总则：像人说话，不像写作文。**
> 本书是恋爱轻喜剧。读者翻开任何一页，应该觉得是在听一个嘴很利索的朋友讲故事，而不是在欣赏一篇散文。
> 风格参考坐标：[[inspirations|灵感来源]] 中登记的《反派少爷只想过佛系生活》一百章以后的部分。

## 一、词汇禁令

### 1. 禁用生僻词、文艺腔

写的每一个词，都要是普通人聊天会用的词。下列类型一律禁用：

- **生僻字词**：眸、颔、倏、怔忡、氤氲、缱绻、旖旎、莹润、冽、湛、魅
- **文艺腔套话**：岁月静好、时光悠悠、命运的齿轮、少年感、氛围感、破碎感、宿命感、温柔了岁月
- **翻译腔**：……的他、在……之中、某种意义上的、不得不说、值得注意的是

### 2. 禁用单字形容词、单字动词

"他很冷""剑很快""她笑得美"——这类独字描摹全部禁止。换成双字词，或者干脆换成动作：

| 禁 | 改 |
|----|----|
| 他很冷 | 他谁都不理 / 他一张脸冷冰冰的 |
| 剑很快 | 剑出得快，看清的时候已经收回了 |
| 她笑得美 | 她一笑，周围人都没话了 |
| 天很蓝 | 天蓝得发亮 |

自然搭配不算违规（"天黑了""他饿了"是活人说的），禁的是把单字当修辞用。

### 3. AI 高频词黑名单

以下词在正文里出现即为事故，改稿时优先清剿：

一丝、一抹、几分、几许、片刻、须臾、刹那、霎时、蓦地、眸光、眼眸、勾起、扬起（嘴角）、浮现、蔓延、弥漫、翻涌、涌上心头、不由得、不禁、仿佛、宛如、恍若、犹如、无声地、静静地、默默地、轻轻地（高频滥用时）、深深地看着、凝视、注视（高频时）、复杂的情绪、说不清的、难以言喻、莫名、某种、空气仿佛凝固、时间仿佛静止、心脏漏跳一拍、呼吸一滞、喉咙发紧、指尖发颤、眼底闪过、嘴角勾起一抹、温声道、轻声道、淡淡道、幽幽道

### 4. 禁用说明式描写和叙述

不许替读者总结，不许给人物的行为写注解。情绪一律用动作、对话、反应带出来：

| 禁（说明式） | 改（呈现式） |
|----|----|
| 他很紧张 | 他把杯子转了半圈，又转回来 |
| 气氛很尴尬 | 没人接话。勺子碰着碗，响了一下 |
| 她心里五味杂陈 | 她张了张嘴，最后只说了句"哦" |
| 诺蕾莉安很害羞 | 诺蕾莉安的耳朵尖红了，话都说不利索 |
| 他被这句话刺痛了 | 他笑了一下，没刚才那么亮了 |

旁白不许下判断（"这是一个温柔的少年""她其实很善良"）。人物是什么人，让他的所作所为自己说。

## 二、句式禁令

### 1. 禁用"动词 + 几"与模糊数字句

"退了几步""沉默了几秒""过了几息""三息之后""五个呼吸"——全禁。要么给具体动作，要么直接跳过去：

| 禁 | 改 |
|----|----|
| 她后退了几步 | 她往后退，一直退到门边 |
| 他沉默了几秒 | 他半天没吭声 |
| 过了几息，他才开口 | 他这才开口 |
| 心跳漏了几拍 | 心口咚的一声（或干脆删掉，写她扶了下桌子） |

### 2. 禁用冒号解释句与对仗说明句

用户钦点的反面教材，正文里不允许出现这种"把话摆整齐了喂给读者"的句子：

> ✗ "条件摆得明明白白：照书里的样子，把这个反派演下去。演一段，给一段活命的奖励。"

冒号在正文里只许用于对话引导（他说：），不许用于"解释设定"。信息要拆开、揉进动作和对话里：

> ✓ "他把话挑明了，就照书里那么演。演得好，才有钱拿。"

同理禁用：排比铺垫、"不是A，而是B"（高频时）、"与其说……不如说……"、三段式列举（"A、B、C，缺一不可"）。

### 3. 禁用破折号强调、禁用金句腔

破折号用于"揭示前的停顿"是典型 AI 习惯。正文破折号只用于对话中的语气打断。凡是听起来"可以印在书签上"的句子，重写。

## 三、"了"与韵律

### 1. 善用"了"

中文的完成感靠"了"撑。"长高了半个头"比"长高半个头"顺耳，"他把茶放下了"比"他放下茶"自然。凡是读着发紧的地方，先试试加"了"、加"了没"。

### 2. 念出来检验

每一段写完，出声念一遍。念着拗口的句子就是坏句子，不许因为"看起来文艺"而保留。特别警惕：连续三个分句一样长、每段结尾都是句号+总结感、四字短语连用（"干净利落，一气呵成"这种）。

### 3. 长短句搭配

短句用来打节拍，长句用来喘气。紧张段落全短句，松弛段落长短交错。如果一段里每句字数接近，必须打断其中一句。

## 四、对话写法

### 1. 对话是主菜

本书叙事密度的目标：**对话占六成以上**。剧情能靠对话推的，就不用旁白推。

### 2. 像人说话

- 真人不把话说完整，会省略、会抢话、会答非所问
- 一来一回要快，能用四个字就不用十个字
- 连续对话可以省略说话人，靠语气区分是谁在说

> ✗ "我认为我们现在应该先去图书馆查阅相关的资料。"
> ✓ "先去图书馆？"
> ✓ "查资料这种事，明天再说。"

### 3. 每个人有自己的嘴

- 伊利安：接话快，爱用打比方，把尴尬的话头顺手接走；不撩自撩，说完了自己没意识到
- 诺蕾莉安：嘴上嫌弃、行动诚实，"麻烦""笨蛋"是口头禅，说完狠话立刻后悔
- 菲拉：句子短，直奔结论，关心人的方式是"你吃了没"；耳朵和尾巴替她说话
- 奥菲莉娅：话少，每句都像顺便说的，损人不带情绪
- 索妮娅：声音轻，措辞客气，偶尔一句话静得让人后脖颈发凉

### 4. 接梗结构

轻喜剧的笑点基本靠"三段式接梗"：A 说正经的 → B 用歪理接住 → C（或旁白）补刀。写完一场戏检查有没有"接住"，没有就补。

## 五、恋爱轻喜剧专则

### 1. 心动靠动作和留白，不靠形容词

> ✗ "她的心跳莫名加快了，一种名为恋爱的情绪在心底蔓延。"
> ✓ "她把这句话在心里过了一遍，又过了一遍，然后发现自己把盐罐拿起来了。"

甜点是具体的：一勺糖、一个发饰、一次"顺路"。写完一个甜点就收，不许解释为什么甜。

### 2. 修罗场靠对话节奏，不靠旁白宣战

两个女主同框，火药味藏在谁先接话、谁把话掐断、谁多看了谁一眼里。禁止旁白喊"气氛剑拔弩张"。

### 3. 吐槽要有来有回

伊利安的幽默是"接住别人"，不是单口相声。每个梗要有人摔、有人接。

### 4. 严肃戏的刹车

本书可以严肃，但严肃段落写完要尽快落地回日常。黑暗戏不超过连续两章，收尾必回暖。

## 六、章节结构

1. **章名**：短。"人名 + 动作"或口语短句（《反派少爷》式："达克迪蒙尝试成为侦探" → 本作如"伊利安不想起这么早"）
2. **开头**：第一句必须有动作或声音，不许景物起手、不许天气起手
3. **结尾**：每章留钩子——一句没说完的话、一个新面孔、一件不对劲的小事。钩子要小而具体，不要大而空
4. **单章体量**：2000～3000 字，一个场景群一件事，不贪多

## 七、自查清单（每章交稿前过一遍）

- [ ] 全文搜一遍黑名单词：一丝 / 仿佛 / 宛如 / 片刻 / 顿时 / 不由得 / 眸 / 勾起——命中即改
- [ ] 搜"了几""几秒""几步""息"——命中即改
- [ ] 有没有单字形容词、单字动词当修辞用
- [ ] 有没有旁白替读者下判断、下总结（"他很温柔""气氛尴尬"）
- [ ] 对话占比够不够？有没有超过五行的纯旁白叙述？有就拆
- [ ] 出声念一遍拗口的地方，加"了"、改短、或者删掉
- [ ] 本章笑点有没有"接住"的结构
- [ ] 章尾有没有钩子

## 八、示例对照（综合）

**坏例（AI 味）：**

> 夕阳的余晖洒在街道上，为一切镀上了一层温暖的金色。伊利安静静地站在那里，望着远去的商队，眸底闪过一丝不易察觉的失落。片刻后，他轻轻叹了口气，转身离去。他知道，属于自己的旅程，才刚刚开始。

**改好（人味）：**

> 太阳落下去，街上的人少了。伊利安在原地站了一会儿，看商队走远，车辙印里积了水，一踩就响。他背起行囊，往港口的方向走。路还长，他先想好了晚饭吃什么。

坏例的问题：全是套话（余晖、镀上、静静地、一丝、片刻、轻轻、眸底），全是说明（失落、旅程开始），没有一件具体的事。改好的版本没有任何情绪词，但"看车辙印积水""先想好了晚饭"把人立住了——这就是本书要的写法。
