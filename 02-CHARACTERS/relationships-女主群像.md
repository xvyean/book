# 女主群像关系

## ⚠ 本文件边界

**收录**：
- 两个角色一旦接触就会持续存在的**结构性调性**（性格特征碰撞产生的稳定模式）
- 开局/初见时就成立的**初始状态**

**不收录**：
- 具体剧情事件（如"某次分组""某次对话"）→ 走 `arc-<角色>-弧线.md`
- 关系演变轨迹（如"从 X 变到 Y"）→ 走 `arc-<角色>-弧线.md`
- 尚未决定的未来走向 → 不写，待决策

**修改原则**：任一角色的 char 卡中**不应再**出现"与其他女主的关系"段落——都迁移到此。char 卡内若需提及，只放一行 wikilink 指针。

## 诺蕾莉安 ↔ 菲拉

**调性关键词**：意外投缘 / 透明度降低警惕

- 菲拉的直球透明到构不成威胁，诺蕾莉安反而放松——这是两人性格特征碰撞产生的稳定模式
- 菲拉会不自觉蹭她、靠她；诺蕾莉安嘴上说"离远点"但不推开
- 但菲拉靠近伊利安时（如靠在他肩上），诺蕾莉安手里物件易碎

**演变 / 具体事件** → 见 [[arc-诺蕾莉安-弧线]] §与菲拉、[[arc-菲拉-弧线]] §与诺蕾莉安

## 诺蕾莉安 ↔ 奥菲莉娅

**调性关键词**：微妙尊重 / 互相识破

- 诺蕾莉安作为精灵，外表年龄判断标准不同于人类——能察觉奥菲莉娅不是真正的少女
- 奥菲莉娅也能一眼看出诺蕾莉安的生命感知不弱
- "互相知道对方不简单"的默契，但不点破

**演变 / 具体事件** → 见 [[arc-诺蕾莉安-弧线]] §与奥菲莉娅、[[arc-奥菲莉娅-弧线]] §与诺蕾莉安

## 诺蕾莉安 ↔ 索妮娅

**调性关键词**：直觉对峙 / 最危险的警惕线

- 诺蕾莉安的生命感知告诉她索妮娅"不对"——情绪太平静、太稳定，像被一层东西盖住
- 她是最可能第一个察觉索妮娅的"巧合"不正常的人，但暂时只有直觉没有证据
- 索妮娅对诺蕾莉安表面温和、内心高度警惕——她清楚诺蕾莉安是最可能揭穿她的人

**演变 / 揭穿节奏** → 见 [[arc-索妮娅-弧线]] §披露节奏、[[arc-诺蕾莉安-弧线]] §与索妮娅

> 注：索妮娅第二学年入学，此关系从她入学时起成立——对叙事时间线而言算"开局调性"。

## 菲拉 ↔ 奥菲莉娅

**调性关键词**：天敌组合 / 无恶意输出

- 菲拉的猫系直觉嗅觉会触发对奥菲莉娅的"闻起来很古老"式观察
- 菲拉对奥菲莉娅**不生敬畏**——这本身就让奥菲莉娅不适应
- 持续的无恶意直球输出（"帮你够书架""你吃饱了没"等调性反复模式）
- 奥菲莉娅处于"弹飞这只猫 vs 她确实没恶意"的持续内耗中

**演变 / 具体事件** → 见 [[arc-奥菲莉娅-弧线]] §与菲拉、[[arc-菲拉-弧线]] §与奥菲莉娅

---

## 菲拉 ↔ 索妮娅

**调性关键词**：猫的直觉 / 单向优待

- 菲拉能"闻"到索妮娅的情绪在某些瞬间剧烈波动——从温和突然变浓、变沉，然后被压回去；她不知道那是什么，每次感觉到会不自觉竖耳
- 索妮娅对菲拉特别好——菲拉是唯一不会用逻辑分析她的人

**演变 / 具体事件** → 见 [[arc-索妮娅-弧线]] §与菲拉、[[arc-菲拉-弧线]] §与索妮娅

---

## 奥菲莉娅 ↔ 索妮娅

**调性关键词**：旁观者洞察 / 外壳下的裂缝

- 奥菲莉娅活得太久，见过太多人——索妮娅的伪装在同龄人面前完美，在她面前有裂缝
- 奥菲莉娅对"人间事务兴趣有限"——她能看穿但不一定立刻出手
- 索妮娅对奥菲莉娅的存在高度戒备——但奥菲莉娅的不朽阶层级让她无法用常规手段应对

**演变 / 揭穿时点** → 见 [[arc-索妮娅-弧线]] §披露节奏、[[arc-奥菲莉娅-弧线]] §与索妮娅
