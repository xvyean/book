# 网文文风手册（正文唯一口径）

> **本手册高于一切设定文档的表述方式。** 设定文档可以写得严谨，正文必须写得像人。
> 所有正文章节，动笔前读一遍「写作禁忌」，成稿后按「自检清单」过一遍。
> 成稿检查可用已安装技能：`story-deslop`（去AI味）/ `humanizer-zh` / `human-writing-zh` / `humanizer`。

---

## 一、这本书的「语言长相」

目标气质：**古典西幻的壳，中文网文的骨，轻喜剧的血。**

- 叙述节奏快，画面先行。一句话能交代的，不写三句。
- 每章两千字上下，必须有推进：事件、关系、笑点、钩子，至少占两样。
- 对话是发动机。能用一场对话演完的戏，不要用旁白讲完。
- 世界观的秘密不靠旁白解释，靠角色的反应、动作、避而不谈。
- 幽默来自角色性格碰撞与具体情境，不来自网络梗、不来自旁白吐槽大会。
- 剑是剑，魔法是魔法，都不许变成说明书。

## 二、扫书心得：中文网文语言要点（长期更新）

1. **动词先行**：「他拔剑」强于「他的剑出鞘了」；动作句短、密、准。
2. **对话带信息与情绪**：每句对白要么推进事，要么露关系，要么逗人笑。废话对白整段删。
3. **心理独白是调味料**：主角内心戏可以俏皮、可以狠、可以怂，但一段里别超过三句连续抒情。
4. **情绪外化，不贴标签**：「她脸色发白」而不是「她很害怕」；「他抄起杯子又放下」而不是「他纠结」。
5. **段落呼吸**：正文一段二到四句，重要单句可独立成段。整页大段落是网文大忌。
6. **章尾钩子**：每章最后一两句，要么出事、要么出人、要么出话，让人想点下一章。
7. **小道具呼应**：一块糖、一根断发、一张旧卡，反复出现三次以上才有分量。别让贵重意象只登场一次。
8. **设定滴灌**：世界观名词第一次出现就跟着场景走，别停下来解释；读者记不住的设定等于没写。

## 三、反AI味 · 写作禁忌（硬性）

### 3.1 程度副词与空泛修饰

尽量删除以下词，删不掉的每千字每种不超过两次：

> 很、非常、极其、无比、格外、颇为、十分、十分地、如此地、莫名地、无端地
> 缓缓、轻轻、微微、悄悄、默默、静静、淡淡、慢慢、渐渐、逐渐

**替代思路**：删掉副词后，如果句子还成立，直接删；如果情绪不够，就换具体动作。

- ✗ 她轻轻地笑了。
- ✓ 她笑了一声，很短。

- ✗ 他缓缓拔出剑。
- ✓ 剑出鞘。没有声音。铁在鞘里磨了太久，早已忘了怎么响。（此处「了太久」反而多余——写成：剑出鞘，没声，像是连铁都在屏息。）

### 3.2 AI高频连接腔与空壳句式

| 禁用/慎用 | 原因 |
|---|---|
| 然而、与此同时、值得注意的是、可以说、某种意义上 | 翻译腔·论文腔 |
| 仿佛、宛如、犹如（每千字不超两处） | AI爱用词，能删就删 |
| 空气仿佛凝固了 / 时间仿佛静止了 / 世界安静得只剩下… | 空镜套话，禁用 |
| 这一刻、那一刻、就在此时（每章不超两处） | 凑紧张感的懒招 |
| 不是…而是…（每章不超一处） | AI最爱句型 |
| 不仅仅…更… / 不仅…还… | AI最爱句型 |
| 随着…/ 伴随着…（每章不超一处） | 翻译腔 |
| 所谓… / 某种程度上 | 评论腔 |
| 映入眼帘 / 映入眼底 | 高频AI词 |
| 嘴角勾起一抹弧度 / 嘴角微扬 | 全网AI共用脸，禁用 |
| 眼神中闪过一丝… / 眼底掠过一丝…（每章不超一处） | 同上，慎用 |
| 深深地看了…一眼 | 同上 |

### 3.3 结构腔

- **禁排比三连**：一个场景里最多一次三连排比，严禁「不是A，不是B，是C」式升华。
- **禁段落末尾总结升华**：场景演完就切，不要补一句「这一刻，他忽然懂了什么是…」。
- **禁章末抒情定格**：除非那是设计好的余韵，否则章末必须是钩子不是诗。
- **禁人人皆作家**：角色说话不像写文章，农夫不打比方，铁匠的比喻都是铁和火。

### 3.4 标点与格式

- 感叹号：每章不超过六个。情绪靠句子本身，不靠符号。
- 省略号：每章不超过三处。结巴不用省略号硬凑。
- 问号连发：「你怎么了？没事吧？到底怎么了？」——情绪炸点偶尔可用，日常禁用。
- 破折号慎用，一章不超过三处。
- 对话分段：一人一句自成一段，动作可挂句后，别把三个人的话塞进一段。

### 3.5 生僻与不自然

- 不堆四字成语（每千字不超两个），不文言单字连发（「甚」「愈」「辄」「竟」按需少量）。
- 比喻必须来自人能摸到的东西：饭菜、铁器、猫狗、雨天、旧伤、铜板。禁生僻博物学意象堆砌。
- 禁现代文明词（引擎、信号、电路、镜头、系统提示之类）出现在这个世界里——包括比喻里。伊利安是转生者，但他本人没有前世记忆，他嘴里永远不会冒出地球词。
- 单字形容词、单字动词可用在短句里制造力度（「她笑。」「风止。」），但不可通篇文言化。

### 3.6 理科禁区（本世界铁律）

正文与设定叙述**一律不得出现**以下思路与词汇：

> 能量守恒、公式、参数、数值、概率、百分比、定律、物理法则、化学、细胞、神经反应、
> 系统、算法、程序、数据、单位换算、计量、回路、蓝量、技能冷却、等级面板、经验条、
> 词条、装备属性、暴击、构建模型、推导、计算、光谱、温度计式的精确数字描述

魔法的描写口径：**仪式、契、名、血、梦、火、影、钟、灰烬、低语**。
魔法是「与古老的东西打交道」，不是「调动资源」。没有人知道它为什么灵验。写它的时候，连角色自己都不该显得全懂。

- ✗ 他把魔力注入回路，术式完成率百分之八十，消耗约三成魔力储备。
- ✓ 他在卡面上划下最后一个记号。风从记号的缺口灌进来，像是有什么东西等了很久，终于被放了出来。

## 四、剑与魔法的呈现口径

### 剑

- 剑招写「身体的记忆」：呼吸、步幅、手腕、铁与骨头。
- 胜负写一瞬，写声音（铁碰铁的脆、破风的闷）、写痛、写灰。
- 剑不是外挂，是练出来的。第一年就该有第一年的笨拙。

### 魔法（卡与典）

- 魔典悬在身侧，像活物。翻页有风，收卡有叹息声。
- 施法三件套（魔典、魔导卡、魔杖）出现时，让动作有仪式感：抽卡、点卡、卡面燃尽成灰或化光。
- 幻兽卡有「活着的卡面」：卡里的兽会睡、会动、会扒拉卡框。
- 神秘性铁律：**魔法可以解释其代价（血、名字、睡眠、记忆、寿命），永远不解释其原理。**
- 高阶力量（奥菲莉娅级）出场时，写「周围人的感受」，不写「力量的构成」。

## 五、自检清单（每章成稿必过）

1. □ 通读一遍：有没有一整句可以整句删掉而不损情节？有就删。
2. □ 副词检查：搜「地」字，能删的删；搜「很/非常/无比」，全删。
3. □ 连接腔检查：搜「然而/与此同时/仿佛/宛如/随着/映入眼帘/嘴角」。
4. □ 理科词扫描：出现即替换（见 3.6）。
5. □ 每段≤4句？章末有钩子或余韵？对话超过全文四成？
6. □ 每章有没有一个「让人记住的画面」？没有就补一个。
7. □ 人物腔调有没有串味：诺蕾不说索妮娅的话，科尔不说薇拉的话。
8. □ 字数：单章 1900–2600 字，不到不回填水话，宁可留钩子收章。

## 六、各角色语言指纹（正文参考）

| 角色 | 说话特征 | 禁 |
|---|---|---|
| 伊利安 | 松弛、自嘲、接话快；对谁都有点温度；心里话比嘴上话多 | 网络梗、说教、油腻 |
| 诺蕾莉安 | 短句、嘴硬、贵族式克制的底子；一慌就变刺 | 解释自己为什么嘴硬 |
| 菲拉 | 短、直、白；比喻来自林子与猎物；爱说「我闻得到」 | 讲道理、学院腔 |
| 奥菲莉娅 | 话少、准、年代久远的用词；讽刺但不出恶言 | 卖萌、少女化语气 |
| 索妮娅 | 轻、慢、敬语周全；答得比问的还圆 | 情绪失控（表层）；内心戏暗涌 |
| 科尔（矮人） | 嗓门大、急、爱拍胸脯；炼成术语当口头禅 | 咬文嚼字 |
| 薇拉（大小姐） | 骄傲但不刻薄；输得起才会赢 | 无脑恶役腔 |
