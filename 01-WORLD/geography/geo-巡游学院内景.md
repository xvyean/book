# 巡游学院 · 内景

> 新生入学手册第一页写着学院的历史、校训与规矩。
> 老生在第一页空白处补了一句真话：「别问它怎么动。问就是钟在指路。」

## 学院是什么

一座浮在海上的白城，沿着内海的航线巡游，每年绕行一周。城基沉在常年不散的雾里——没人见过城底。帆没有，桨没有，它就这么走。

学院的钟（长庚塔的塔钟）每天三响。靠港、离港、学年始末，都按钟声来。

## 主要场所

| 场所 | 说明 |
|---|---|
| **铜门与白垩广场** | 正门。广场中央有一口喷泉，水据说引自内海最深处——冬天不冻，传说喝了会梦见海（新生必试，试完多半只是拉肚子） |
| **术理堂** | 主教学楼：术理课、制卡史、符文课（旧称）都在这。钟楼式建筑，走廊挂满历代名人的画像——画像的眼睛会跟着人转（新生被吓哭过） |
| **演武坪** | 剑科场地，临海一侧。海风终年不断，剑穗生说「风是第二把剑」。木剑架堆在坪角，剑科的等级不看成绩，看木剑上的刻痕 |
| **炉翼楼** | 炼成工坊。楼顶常年冒三种颜色的烟。一楼对工科开放，二楼以上要申请——科尔的梦想是炸到三楼去 |
| **星枢阁** | 星象与航海课所在。顶层是环形露台，学院巡游时这里是看星星最好的地方。海图室在露台下面一层——锁着，钥匙在老院长手里 |
| **藏书院** | 奥菲莉娅的地盘。迷宫一样的书架，灯会自己跟着人走；借书不登记，还书看良心。最深处有一架「没有书名的书」——想看的人要先回答守门猫头鹰的问题（猫头鹰是假的，书是真的） |
| **长庚塔** | 全城最高的钟塔。塔钟在顶，钟室归卡西安。塔下七层是旧城——越深越旧，第七层之下禁止进入。钥匙三把：钟楼守一把，院长一把，还有一把没人知道在谁手里 |
| **宿舍塔** | 北塔（男）、南塔（女）、东塔（混龄留学生）。塔间有廊桥，廊桥顶有条「猫道」——据说猫科亚人的学生都从那儿走。北塔四层丙室：伊利安、科尔、洛塔、雷欧 |
| **长桌厅** | 食堂。一条长桌能坐三百人。掌勺的圆脸大妈记得每个学生的食量，伊利安入学第一周就因「太能吃」在长桌厅出名 |

## 塔底的传说（学生间的版本）

- 版本一：塔底下是旧城——学院是「把一座老城驮在背上」建起来的，下面全是没人住的空房子。
- 版本二：下面封着学院不要的东西。
- 版本三（最不受欢迎）：下面有口井。井里有钟。钟里有名字。
- 说版本三的学生会被老生嘘：「少听沉钟城的人讲古。」

## 写作注意

- 学院是流动的：同一扇窗，秋天看得到沉钟城的灯火，冬天看得到雾牙城的冰棱——这种「窗外在变」是学院独有的抒情位。
- 场所与伏笔：白垩广场的井（意象）、长庚塔的塔底（主线）、藏书院的海图室（卷二钩子）、猫道（菲拉专用喜剧通道）。
