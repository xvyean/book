# 地理

## 概述

这个世界的地理不应被理解为"几个王国分完地图"，而应理解为一套彼此咬合的文明生态。世界采用"中央内海 + 多板块 + 巡游学院"结构，地理的基本单位是文明单元（王国、林地联邦、山城联盟、混居城邦、游牧边疆等），而非国界。种族的空间呈现遵循"母地层 + 流散层"双层模型。
