# 纪元总览

## 概述

本篇整理这个世界从远古到当今的**时代划分骨架**。它不试图穷举所有历史事件，而是给出一个可以往里填充细节的框架。五大纪元的划分依据是**世界秩序的每一次根本性变动**——法则成形、神明觉醒、魔导术突破、降临协议签订。

> **AI 速读**：五大纪元依次为 ①混沌纪（无时间）→ ②黎明纪（神明觉醒与种族诞生）→ ③神权纪（神明直接统治凡间）→ ④魔导纪（凡人崛起与弑神）→ ⑤协约纪（当今，降临协议后的均衡时代）。每一纪的终结都对应一次世界秩序的根本断裂。

## 第一纪 · 混沌纪

> 无人见证的时代。没有历史，只有后来者的追溯。

### 核心链条

原初混沌自行裂解 → 第一道裂隙 → 法则流出（秩序、时间、生灭、变化） → 诸法彼此制衡 → 世界在法则争衡中缓慢凝形 → 强大法则凝聚出无人格的**法则雏核**。

### 设定要点

- 没有人格化创世者，混沌不是创世神
- 法则先于一切存在
- 法则雏核此时只有领域本能，没有意志与名字
- 此纪无"时间"概念可言，因为时间法则本身也在此阶段诞生

> 详见 [[religion-创世神话总纲#一、混沌不是创世者]]

## 第二纪 · 黎明纪

> 生灵出现，歌声响起，沉默的法则之核被一一点亮。也正是在这一纪，众生的阴暗面催熟了第一批邪神。

### 核心链条

大地草木兽群出现 → 智慧种族诞生（[[culture-人类|人类]]、[[culture-精灵|精灵]]、[[culture-矮人|矮人]]等先祖） → 祈求、记忆、歌唱、争斗的积累 → 法则雏核被**点灵** → 神明获得名字、倾向与意志 → 正神、中立神相继成形 → 众生极端欲望与恐惧催熟了邪神异化 → **驱邪之战**爆发。

### 关键事件

| 事件 | 说明 |
|------|------|
| **种族诞生** | [[culture-人类|人类]]、[[culture-精灵|精灵]]、[[culture-矮人|矮人]]、[[culture-海族|海族]]等先祖在不同法则环境中分化成形 |
| **神明觉醒** | 法则雏核在长期信仰积累中被点灵，17 位已知神明并非同时觉醒，先后跨越了漫长岁月 |
| **邪神异化** | 死亡领域的阿布隆、克洛萨，生命领域的维萨斯，混沌领域的赛尔坎，黑暗领域的诺萨斯——被众生阴暗面催熟 |
| **驱邪之战** | 正神联合凡间力量，将邪神逐出主世界，迫使其退入远方魔界。此战奠定了正/邪根本对立的格局 |

### 纪元终结标志

驱邪之战胜利，**十二道门扉**被封印，邪神被隔绝于魔界。正神开始以守护者姿态直接参与凡间事务。

> 详见 [[religion-创世神话总纲#三、法则雏核与"点灵"]]、[[religion-创世神话总纲#四、邪神的来源]]

## 第三纪 · 神权纪

> 诸神之治。正神以守护者自居，直接干预凡间秩序，建立了强大的神殿体系。这是信仰最稳固、同时也是凡人最缺乏自主权的时代。

### 核心链条

邪神被驱逐 → 正神直接降临凡间 → 神殿体系建立 → 种族得到快速发展与稳定庇护 → 信仰高度集中于正神 → 凡人对法则的自主探索被长期压制 → **符文术萌芽**（炼金术与符文学的原始结合）→ 第一批原始炼成术出现。

### 关键事件

| 事件 | 说明 |
|------|------|
| **神殿统治** | 正神直接降临或通过强力代行者治理凡间，各大种族在神殿体系下获得庇护与发展 |
| **种族文明定型** | [[culture-人类|人类]]平原王国、[[culture-精灵|精灵]][[geo-精灵林地|林地邦域]]、[[culture-矮人|矮人]]山城体系在此纪基本成型，各自信仰与文化传统在神权背书下稳定 |
| **十二门扉的守护** | 封印邪神的十二道门扉成为世界安全的关键节点，每一道门扉附近都发展出守护者据点和监视者体系 |
| **符文术萌芽** | 少数天才凡人开始独立探索法则——最初的成果是炼金术与符文学的原始结合，但在神殿看来属于僭越 |
| **大地与海洋格局形成** | 中央内海成为文明交通核心，主舞台板块的六种文明空间基本定型 |

### 纪元终结标志

符文术突破量变临界点，第一位成功将术式封存于介质的先驱出现——这就是**魔导卡体系的雏形**。知识不再是神的专利。

## 第四纪 · 魔导纪

> 大魔导师时代。这是凡人力量爆发式增长的时代。古代大魔导师触碰法则、创造真理卡、斩杀神明——世界秩序被彻底改写。

### 核心链条

魔导卡体系从雏形走向成熟 → 炼成工艺体系化（核心阵/辅助阵/定向阵/升华阵四类确立）→ 阶位与造诣双轴评价体系成型 → **古代大魔导师群体崛起** → 不朽阶强者频繁触碰法则、创造真红造诣卡牌 → 生命法则被解构，进化卡与融合卡的定向炼成阵被创造 → 召唤卡流派击败传统魔法炮台流派 → **第一位神明被凡人斩杀** → 整个正神阵营震动 → **降临协议**被迫签订。

### 关键事件

| 事件 | 说明 |
|------|------|
| **魔导卡体系成熟** | 施法三位一体（魔典+卡牌+魔杖）从实验性技术变为普世训练体系，12 阶×五色造诣体系被确立 |
| **古代大魔导师崛起** | 一批不朽阶魔导师凭借对法则的深度领悟，创造大量真理卡，力量达到可与低阶神抗衡的层次 |
| **生命法则被解构** | 最具里程碑意义的事件之一——某位（或某几位）大魔导师成功解构了生命法则的"进化"与"融合"分支，将其固定为可批量复制的定向炼成阵 |
| **召唤卡主流化** | 进化卡与融合卡的出现使召唤卡战术深度远超传统魔法炮台流派，彻底改变了魔导界的战斗范式 |
| **弑神事件** | 第一位神明被凡人斩杀。具体是哪位神明、在什么条件下被杀、由谁执行——留待后续细化 |
| **降临协议签订** | 正神震动，意识到凡人已具备威胁神位的能力。正神之间达成协议：正常情况下不得直接降临主世界 |
| **邪神趁乱反扑** | 在正神与凡人博弈的缝隙中，邪神势力通过门扉裂隙发动多次侵蚀，多道门扉曾一度出现松动 |

### 纪元终结标志

降临协议签订。正神退居幕后，此后只通过神选者、神役者、神谕和圣物间接影响主世界。

> 详见 [[magic-真理卡#一、历史起源]]、[[religion-神明阵营与降临#三、正神降临协议]]

## 第五纪 · 协约纪（当今）

> 均衡与暗涌并存的时代。正神退场后的权力真空由凡人自行填补，奥尔德林学院建立，多文明格局定型——但十二门扉持续衰弱，邪神的侵蚀从未停止。

### 核心链条

降临协议生效 → 神殿权威大幅下降 → 各族凡人政权开始独立运营 → [[culture-人类|人类]]王国、[[culture-精灵|精灵]][[geo-精灵林地|林地邦域]]、[[culture-矮人|矮人]]山城联盟各自壮大 → **奥尔德林学院建立**，成为跨种族知识中心 → 沿海城邦带繁荣为多种族混居的开放空间 → 魔导师行会与学院体系成为社会主流力量之一 → 十二门扉逐渐衰弱，边疆据点偶发邪神侵蚀事件 → 旧日大魔导师的遗产被争夺。

### 关键事件

| 事件 | 说明 |
|------|------|
| **后神权时代** | 神殿不再是绝对权威，但仍保有巨大社会影响力。各族信众仍然虔诚，但"神不随意降临"已成常识 |
| **奥尔德林学院建立** | 一座不隶属任何政权、浮于海面的漂移岛群学院（奥尔德林魔法学院）按古老法则漂移于各大陆之间，成为各族精英汇聚、知识交流与异端学说碰撞的核心 |
| **多文明均衡** | 人类王国腹地、精灵林地、矮人山脉、沿海城邦带、边疆游牧区与地下据点六种文明空间并存竞争 |
| **门扉衰弱** | 驱邪之战至今已过漫长岁月，十二道门扉的封印力量持续消耗，部分门扉已出现松动迹象 |
| **大魔导师遗产争夺** | 古代大魔导师留下的真理卡、定向炼成阵图纸、法则研究手稿和遗迹成为各方势力争夺的核心资源 |
| **暗流涌动** | 邪神教派暗中活动，试图从内部腐化门扉守护者；部分野心家研究凡人成神路径；某些旧日真理卡的再发现可能改变力量平衡 |

### 当前局势

- **表面均衡**：各族各势力在贸易、知识与信仰的框架内保持微妙平衡
- **深层危机**：门扉松动、邪神侵蚀加剧、旧日遗产引发争夺、凡人成神研究触动诸神底线
- **故事起点**：主角最可能在这个表面平静、暗涌不断的时代登场
