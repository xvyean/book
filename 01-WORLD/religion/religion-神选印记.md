# 神选印记

## 概述

神选印记是神明在凡人身上留下的关注标记，代表"我对你感兴趣，我在看你"。它是成为正式 [[religion-神选者与神役者|神选者]] 的前置条件，但并不保证最终一定会完成神选。

> **AI 速读**：神选印记 ≠ 神选。印记是单向的（神明→凡人），正式神选是双向确认的法则纽带。携带印记的凡人可能终其一生都不会成为正式神选，也可能在某个关键时刻完成转化。

## 一、定义

神明观察凡人世界时，偶尔会对某个凡人产生兴趣——可能因为此人的性格、行为、理念或身上承载的矛盾恰好与该神明的法则产生共振。此时神明可以选择在此人身上留下印记，表示持续关注。

印记本身不赋予力量，不建立义务，不构成契约。它更接近：神明伸出了手，但还没有握住。

## 二、印记与正式神选的区别

| | 神选印记 | 正式神选 |
|---|---|---|
| 性质 | 神明的单向关注标记 | 双向确认的法则纽带 |
| 力量 | 极微弱，近似无 | 获得与法则相关的赐福能力 |
| 约束 | 无义务、无契约 | 信仰纽带（神选者）或契约束缚（神役者） |
| 可感知性 | 携带者隐约知道"有什么在看我"；高阶神职者或法则敏感者能模糊嗅到 | 法则烙印明确可辨 |
| 可撤回 | 神明可随时收回关注 | 断开纽带有严重后果（见 [[religion-神选者与神役者#五、失去赐福的后果]]） |

## 三、印记的外在表现

印记的表现因神明不同而不同，通常与该神明的法则领域微弱相关：

- 表现极其轻微，容易被归因为"天赋好""性格如此""运气"
- 只有对法则高度敏感的人（高阶神职者、某些真理卡持有者）才可能察觉"这个人身上沾了点什么"
- 携带者本人通常只有模糊的感受，不会明确知道自己被哪位神明标记

## 四、从印记到正式神选

完成条件因神明而异。共通的逻辑是：**携带者自身的成长走到了与该神明法则深度共振的临界点。**

不是考验、不是信仰虔诚度测试，而是法则层面的自然响应——当一个人的内在状态与某位神明的法则领域产生足够深的契合时，印记会自然完成为正式纽带。

这意味着：
- 有人可能携带印记一生都不完成（未达到共振条件）
- 完成的时刻往往与携带者人生中的关键转折重合
- 神明不能强制完成（这与神役者的不平等契约不同）

## 五、已知案例：伊瑟拉的神选印记

[[religion-神明-伊瑟拉]] 的神选印记具有双面特征，与她同时掌握爱与欲望两面法则一致：

**爱的面向**：携带者靠近受伤或痛苦的人时，对方会感到超出正常的安心感。很轻微，容易被归因为"这个人就是让人安心"。

**欲望的面向**：携带者在压抑某种在意或渴望时，身上会散发出微妙的吸引力，让靠近的人心跳加速或难以移开视线。携带者本人意识不到。

**完成条件**：当携带者内心关于"爱与欲望"的矛盾走到临界点——不再将自己的偏爱和渴望伪装成责任与善意，而是真正面对并承认——印记会完成为正式的神选纽带。
