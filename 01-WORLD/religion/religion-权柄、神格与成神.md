# 权柄、神格与成神

## 概述

本篇处理神明设定里最核心也最危险的一层：谁掌握什么法则、神明为什么彼此厮杀、神格碎片有什么价值，以及凡人是否可能跨过神与人的分界线。

> **AI 速读**：同一大法则领域可以被多个神明分别持有不同分支。神明争斗的核心不是领土，而是**权柄**。击杀同领域神明、夺取其 [[#三、神明死亡与神格|神格]]，是完全掌控某一法则领域的主要路径。凡人成神的关键门槛不是单纯变强，而是**让神国诞生**。

## 一、法则领域细分

同一大法则领域之下，可以存在多个细分分支。

| 大领域 | 细分示例 |
|------|----------|
| 死亡 | 自然死亡 / 杀戮 / 腐化湮灭 |
| 生命 | 自然生长 / 腐化衰败 / 进化 / 融合 |
| 命运 | 秩序 / 因果 / 偶然 / 断裂 |

规律如下：

- 同领域神明天然存在竞争关系
- 他们通常知道彼此存在
- 但无法直接篡改对方已稳定掌握的子领域

## 二、权柄争夺

**完全掌控一个法则领域的唯一路径，是吞并该领域全部持有者的权柄。**

常见手段：

- 击杀同领域神明
- 吸收其神格并长期消化
- 抢占其信仰网络
- 夺取其在主世界的法则锚点与代行者系统

因此，神明战争的本质是**法则掌控权的争夺**，不是单纯阵营对抗。

## 三、神明死亡与神格

神明是可以被击杀的。

神明死亡后：

- 尸体或遗留结构中会残存法则之力
- 这部分力量会凝聚为可被争夺的 [[#三、神明死亡与神格|神格]]
- 击杀者可吸收神格，逐步掌握对方法则
- 未被完全继承的部分法则之力会重新回归世界

> [!warning] 剧情价值
> 神格碎片是极高价值道具。它既可以是神明战争的战利品，也可以是凡人接触法则的危险媒介。

## 四、凡人成神的路径

### 关键认知

- 不朽阶魔导师不等于准神
- 神明与凡人之间存在量变后的质变鸿沟
- 真正的分界点不是“更强”，而是“能否让神国诞生”

### 路径概括

魔导师 → 不朽阶 → 深度触碰某条法则 → 神国诞生 → 神明

### 神国的意义

神国不是普通居所，而是**法则掌控力的实体化**。

- 神明在神国内几乎具备绝对优势
- 神国越稳固，神明越难被根本性击坠
- 没有神国，就没有成熟神明意义上的法则主权

## 五、主世界与神国的差别

| 场景 | 神明状态 |
|------|----------|
| 主世界降临 | 受压制、受坐标限制、消耗巨大 |
| 自身神国内 | 对法则的调动接近绝对 |

这也是为什么凡人在主世界有机会与低阶神抗衡，但进入神国则几乎没有胜算。

## 六、与真理卡的张力

- 神明通过神格长期掌控法则
- 魔导师通过炼成偶然触碰法则
- 真理卡是法则触碰被封存后的产物

这带来一个长期悬念：

> 当某条法则已被某位神明深度掌控时，该领域的 [[magic-真理卡|真理卡]] 是否会与其产生天然共振、冲突，甚至被其察觉？
