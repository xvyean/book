# 神明名录

## 概述

## 按与真理卡的关联度导航

| 关联强度 | 神明 | 说明 |
|------|------|------|
| **强关联** | 菲尔格、依若斯、奥瑟恩、伊瑟拉 | 直接与炼成、时间系、知识系、执念系真理卡形成设定张力 |
| **中等关联** | 卡尔涅斯、泰奥斯、索菲莉娅 | 存在典型领域真理卡或精神系底层联系，但不以炼成为核心身份 |
| **冲突型关联** | 阿布隆、索伦、克洛萨 | 与法则权柄、灵魂归属和真理卡副作用存在高冲突潜力 |
| **弱关联** | 薇尔涅、维萨斯、瓦尔达、赛尔坎、诺萨斯、涅瑞斯、塔尔贡 | 法则领域与真理卡体系交叉较少，但可通过对位效果间接关联 |

## 关系矩阵速查

> 仅列核心高相关组合。详见各神明个档的「神明关系」章节。

| 关系 | 双方 | 性质 |
|------|------|------|
| 协作 | 卡尔涅斯 ↔ 索伦 | 命运与轮回高度协作 |
| 天然合作 | 塔尔贡 ↔ 菲尔格 | 大地提供矿物，锻造赋予形态 |
| 深层敌对 | 索伦 ↔ 阿布隆 | 轮回与湮灭根本冲突 |
| 根本对立 | 塔尔贡 ↔ 阿布隆 | 稳固存在 vs 湮灭消失 |
| 法则争夺 | 索伦 ↔ 克洛萨 | 同属死亡领域，分支冲突公开化 |
| 法则竞争 | 薇尔涅 ↔ 维萨斯 | 自然生命与腐化生命对立 |
| 领域摩擦 | 涅瑞斯 ↔ 泰奥斯 | 海上风暴的管辖权争议（低烈度） |
| 领域擦边 | 涅瑞斯 ↔ 诺萨斯 | 深海黑暗 vs 黑暗恐惧，边界模糊 |
| 深层对立 | 奥瑟恩 ↔ 赛尔坎 | 知识与欺骗根本冲突 |
| 信息交叉 | 索菲莉娅 ↔ 卡尔涅斯 | 梦中预兆 vs 命运预言，方式不同但有时指向相同 |
| 知识重叠 | 索菲莉娅 ↔ 奥瑟恩 | 潜意识知识碎片 vs 系统化知识 |
| 欲望映射 | 索菲莉娅 ↔ 伊瑟拉 | 梦境常映射欲望，但两者法则独立 |
| 被警惕 | 卡尔涅斯 → 伊瑟拉 | 欲望与爱是命运系统中的不稳定变量 |
| 合作 | 诺萨斯 ↔ 赛尔坎 | 欺骗需要恐惧，恐惧需要欺骗来维持 |
