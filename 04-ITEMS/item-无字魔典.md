# 无字魔典（Grimoire）

## 概述

无字魔典是魔导师施法体系「三位一体」的核心组件之一，与魔导卡、魔杖共同构成完整施法架构。它是所有魔导卡的**物理容纳与抽调中心**——没有魔典，卡牌无法被调用，魔力也无从流向术式。

> **AI 速读**：无字魔典 = 卡组容器 + 抽调终端。容量上限随阶位提升（1阶5张，六阶封顶30张）。普通卡可随时移入移出。魔典负责收纳、抽调、切换卡牌。

---

## 一、外观与物理特征

- **形态**：一本厚重的古典典籍，封面材质因制作者偏好与魔力属性不同而各异（常见皮革、金属封皮、符文晶板装订等）。
- **悬浮特性**：使用状态下自动悬浮于魔导师身旁（通常位于持杖手的另一侧），无需手持即可运作。
- **「无字」的含义**：魔典内部无任何固定铭文。翻开内页一片空白——内容由收纳其中的魔导卡构成，而非刻印的固定法阵。这正是其名称的由来。
- **外观活化**：携带高阶幻兽卡的魔典封面有时会出现轻微的符文光晕，与卡牌属性共鸣。

---

## 二、核心功能

### 收纳
魔导卡在不使用时以压缩态储存于魔典内部空间，处于低耗待机状态。普通卡可随时移入或移出魔典。

### 抽调
魔导师施法时，魔典自动将对应卡牌弹出至半空，呈现可供魔杖激活的悬浮状态。抽调速度与魔导师的魔力精度和阶位直接相关。

### 卡组容量上限

| 阶位 | 最大收纳卡数 |
|------|------------|
| 1阶 | 5张 |
| 2阶 | 10张 |
| 3阶 | 15张 |
| 4阶 | 20张 |
| 5阶 | 25张 |
| **6阶及以上** | **30张（上限锁定）** |

超出当前容量上限的卡牌无法被收入；更换卡组构成须先移出现有卡牌。

> 阶位提升时，灵魂承载与魔典容量同步提高。幻兽卡和普通卡一样会占用魔典卡槽；魔典负责收纳、抽调、切换卡牌。详见 [[magic-阶位造诣体系#1.4 无字魔典卡组容量上限]]。

## 三、制作与获取

无字魔典属于高级魔法工具，制作工艺远比普通魔导卡复杂：

- **专业制作**：通常由专精器具炼成的工匠魔导师制造，非普通制卡师能力范围。
- **市场流通**：高端魔法器具商行有成品出售，但品质参差；顶级魔典多为定制或传承。
- **装载规则**：普通卡可随时移入移出魔典；魔典承担卡组管理功能，不参与幻兽卡的认主过程。

## 五、规则硬性限制

- 魔典容量上限**不能**被任何外部手段临时扩充，只能随阶位晋升解锁。
- 六阶后容量固定为**30张**，不再随阶位增长。
- 普通卡**可以**随时移入移出魔典；超出当前容量的卡牌无法被收入。
- 魔典损毁或缺失时，魔导师**无法调用**任何魔导卡，施法能力完全丧失。
