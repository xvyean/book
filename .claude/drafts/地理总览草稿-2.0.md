# 地理总览草稿 2.0

## 概述

这个世界的地理不应被理解为“几个王国分完地图”，而应被理解为一套彼此咬合的**文明生态**。

世界整体采取“**中央内海 + 多板块 + 巡游学院**”结构。中央内海负责连接各地文明；主舞台板块承载当前最重要的政治、宗教与冒险冲突；其余板块保留为背景文明来源；巡游学院则独立于所有政权与母地之外，作为世界性的流动知识中心长期影响各地。

在这个框架里，王国只是**人类腹地文明**的典型组织形式之一。精灵林地、矮人山城、港口城邦、边疆部族带、地下据点与群岛航路同样都是一级地理单位。

## 核心原则

### 一、地理的基本单位是文明单元，不是国界

地图上最重要的，不是谁画出了边境线，而是谁在一片空间里持续生活、建造、祭祀、贸易、战斗，并留下了稳定的文化痕迹。

因此，这个世界的核心地理单位应包括：

- 人类王国腹地
- 精灵林地邦域
- 矮人山城联盟
- 游牧与部族边疆带
- 海港混居城邦圈
- 地下与边缘据点
- 独立巡游学院

其中有些是国家，有些是联盟，有些是文化区域，有些是贸易网络，有些则根本不承认“国家”这一套边界逻辑。

### 二、种族的地理呈现采用“母地层 + 流散层”

每个主要族群都应同时拥有两种空间存在方式：

- **母地层**：解释它的文化根源、建筑风格、祖先记忆、主流信仰与社会组织从何而来
- **流散层**：解释它为什么会出现在港口、学院、商路、边疆、军镇与他族城市中

这样既能保留“这个种族从哪里来”的厚度，也能避免世界变成“一族一块拼图大陆”的游戏地图。

### 三、中央内海沿岸默认是混居最强的区域

中央内海不是单纯的海域，而是这个世界的交通、贸易、知识与信仰交换轴。

沿岸港口和群岛天然会形成：

- 多种族混居
- 多神信仰并存
- 多语言环境
- 黑市和情报网
- 外来学派和异端教义
- 旧遗物与新财富同时聚集的城市生态

如果说人类腹地代表“秩序的自我想象”，那么中央内海沿岸就是“世界真实混杂的样子”。

## 世界整体骨架

当前可暂定为六层结构：

| 层次 | 性质 | 作用 |
|------|------|------|
| **中央内海** | 文明交通核心 | 连通主要板块与港口文明，是贸易、战争、宗教与知识流动主轴 |
| **主舞台板块** | 当前最重要的大陆区域 | 容纳腹地王国、林地邦域、山城联盟、沿海城邦与边疆遗迹 |
| **其他三大板块** | 远方背景文明 | 提供异文化、异种族、古老传统与外部压力 |
| **群岛与航路带** | 过渡地带 | 多种族混居、海商、海盗、自由港与流亡者聚集 |
| **巡游学院航线** | 独立流动结构 | 串联各地停靠点与知识圈，打破母地封闭 |
| **外海危险圈** | 文明边缘之外 | 深海、风暴海、门扉污染区、失落遗迹与极端环境所在 |

## 中央内海

中央内海是世界的心脏。

它决定了这个世界不会变成互相隔绝的大陆拼盘，而是一个长期接触、长期误解、长期互相影响的文明网。

围绕中央内海，最容易自然形成的空间包括：

- 巨型港口城市
- 海商共和国或城邦联盟
- 神殿与商会共治城市
- 走私和合法贸易并存的自由港
- 航海学校、星象塔、接引高台
- 外来使团、佣兵与翻译者的常驻聚落

宗教上，这里也是多神并存最明显的地区。航海者、商人、工匠、恋人、军人和亡者家属，往往会分别向不同神明祈祷。同一座港口里出现 [[religion-神明-涅瑞斯]]、[[religion-神明-泰奥斯]]、[[religion-神明-菲尔格]] 甚至 [[religion-神明-伊瑟拉]] 不同面向的祭坛，都是很自然的事。

## 主舞台板块

主舞台板块不是“一整片统一国家”，而是当前故事最常用的一整套文明叠层。

它至少应同时包含以下六种空间：

### 一、人类王国腹地区

这里以平原、河谷、旧都、农耕腹地和传统道路网为主，是王权、贵族制度与正统神殿最稳固的地方。

这个区域适合出现：

- 数个彼此竞争或联姻的人类王国、公国、旧侯领
- 正统史书和正统教义的话语中心
- 大量人口与稳定税赋
- 视自己为“文明正统”的保守阶层

但它不应被写成整个世界的唯一中心。它只是**人类秩序的中心**，不是全部文明的中心。

### 二、精灵林地邦域

精灵不应被安排为一个封闭统一帝国，而更适合写成若干古老林域、月庭聚落、湖畔圣林与树城共同构成的松散文明圈。

其特征是：

- 边界模糊，常以森林边缘、古树带、圣泉和旧誓约划分势力
- 政治上更偏向议会、血脉、长时记忆和古盟约，而非单一王座
- 与 [[religion-神明-薇尔涅]]、梦境、月相、古老生命法则相关的信仰更浓
- 对真理卡和炼成术既可能高度精通，也可能带有强烈禁忌意识

这些林地邦域构成精灵的**母地层**。而在港口、学院和商路上出现的精灵学者、医者、使节、游侠和翻译者，则构成它们的**流散层**。

### 三、矮人山脉区

矮人文明更适合呈现为“山城联盟”而不是“矮人大王国”。

它们分布在矿脉山系、地下城廊、高地要塞和熔炉城之间，由旧誓约、血亲行会、矿脉共享与战争盟约维系。

其特征是：

- 空间上垂直展开，地表堡垒与地下交通同样重要
- 与 [[religion-神明-塔尔贡]]、[[religion-神明-菲尔格]] 的信仰联系最强
- 炼成材料、军械、构装、矿石贸易和地基工程是其影响世界的主要方式
- 对外扩张不一定强，但对山脉和矿路控制极强

这片区域解释了矮人的文化根源；而在腹地军械坊、港口工坊、学院炼成学部中常见的矮人工匠、匠师与导师，则体现其流散层。

### 四、沿海混居城邦带

这是主舞台板块最开放、最复杂、最容易“发生故事”的区域。

它由多个港口、河口、湾岸城市、礁港与商路节点组成，政治形态可能是：

- 城邦共和
- 商会寡头
- 神殿与港务议会共治
- 雇佣兵保护下的自由港
- 名义隶属王国、实则高度自治的贸易都会

这里天然适合体现：

- 人类、精灵、矮人、海上族群和边疆血脉长期混居
- 多信仰并存但都不彻底占优
- 正统与异端只隔一条街
- 学院停靠时形成短期爆发式繁荣
- 情报、材料、旧遗物、走私卡牌和外来工艺持续流动

如果主角未来来自一座“看起来最像世界缩影”的城市，那么它多半会出现在这片区域。

### 五、边疆游牧与遗迹区

边疆不是“无主荒地”，而是另一种文明形态。

这片区域位于荒原、台地、寒原、裂地、旧战场和古代遗迹密集地带，适合容纳：

- 游牧部族
- 兽人或半兽人血脉共同体
- 草原民、混血战团、边防军镇
- 门扉监视者
- 废墟寻宝者与遗迹学派

这里的政治不一定稳定，但绝不代表没有秩序。它们可能依靠季节迁徙路线、祖灵誓约、战团盟誓、泉眼和牧场权利来维持秩序。

对腹地王国而言，这里是边缘；但对世界本身而言，这里是危险与变化最先发生的前线。

### 六、地下与边缘据点

并非所有文明都以“在地表大面积公开定居”来表现自己。

一些流亡族群、禁忌学派、门扉看守者、被污染后退入地下的残存共同体，或不愿接受地表统治秩序的族群，都会在地下城廊、崖壁城市、裂谷洞窟、沉埋遗址中形成据点网络。

它们的重要性不在于人口规模，而在于：

- 它们保存了别人已经失去的知识
- 它们常是灾难最先抵达、也最先察觉异常的地方
- 它们为世界提供了非正统的历史视角

## 主要族群的空间呈现

现阶段可先采用宽框架，而不急着锁死全部族群名单。

| 族群大类 | 母地层 | 流散层 |
|------|------|------|
| **人类** | 平原河谷、旧都、腹地王国与教区 | 港口官吏、商人、士兵、神职者、学院学生几乎遍布各地 |
| **精灵系** | 圣树林、月庭聚落、林地邦域、湖畔古居 | 医者、学者、翻译者、游侠、学院研究者常见于港口与学院 |
| **矮人系** | 山城、矿堡、地下城廊、熔炉都市 | 工匠、军械师、建筑师、矿务顾问与导师活跃于商路和学院 |
| **边疆部族 / 兽人系** | 荒原、台地、寒原、裂地周边的战团与聚落 | 佣兵、向导、边军、骑手、遗迹探索者和学院武技系成员 |
| **海上族群** | 群岛、礁港、潮汐圣地、海峡聚落 | 航海者、领航员、港口祭司、海商与学院星航学徒分布于各港 |

这张表的重点不是统计人口，而是明确一件事：**所有主要族群都既有根，也有流动性**。

## 巡游学院

巡游学院是这个世界最重要的独立地理奇观之一。

它不是某国领土内的学院，也不是一座普通的浮空城市，而是一座沿着古老法则航路、按半固定周期巡游世界的学院城。

它的几个核心属性必须被固定下来：

- **独立性**：不隶属于任何王国、教廷、山城联盟或林地邦域
- **周期性**：不是随机出现，而是按古老星历、潮汐、法则回路或观测周期巡游
- **接引性**：只有在若干港口、观测塔、接引高台或古老圣所附近，人才最容易登上学院
- **中立性**：它长期保持超然，但绝不意味着它没有自己的规则和偏见
- **多种族性**：它必须是世界性机构，不是人类专属学府

巡游学院的存在，会直接改变世界地理的运行方式：

### 一、打破母地封闭

林地邦域不会永远只关在森林里，山城联盟也不会永远只把知识锁在矿脉之下。学院的航线让各族精英、流亡者、天才与异端都拥有离开母地、进入更大世界的路径。

### 二、制造知识不均衡

学院半固定地经过某些港口和节点，这意味着被航线长期覆盖的城市，会更早接触新炼成术、新卡牌构筑、新星象学和旧时代残卷。

反过来，不在航线上的腹地地区往往更保守，也更容易把学院视作危险的不稳定因素。

### 三、自然形成多种族知识圈

学院停靠、低飞、投下接引桥或开放招生窗口的地方，会逐渐发展出：

- 多语言市场
- 书商与抄写人
- 寄宿区和学徒街
- 材料黑市
- 接引祭典和送别仪式

于是，学院本身是流动的，但围绕它的知识生态会在固定节点沉淀下来。

## 其他三大板块

世界不止一个主舞台板块，但现阶段不需要全部细化。

其余三大板块可以先只保留功能定位：

### 一、古老异文明板块

更适合容纳历史更深、与中央内海秩序联系较弱的古文明、异族大聚落或未完全并入主舞台叙事的古老社会。

### 二、极端高地与寒境板块

用于承载更极端的山原文明、苦寒种族、封闭要塞和远离内海航线的古老共同体。它既可以和矮人文明产生呼应，也可以留给未来新增族群。

### 三、河谷 / 沙海 / 远方商路板块

负责提供远方货物、独特宗教仪式、异域命名风格和“世界真的很大”的感觉。它不必现在展开，但它的存在能防止世界规模被压缩成“内海周边一圈人”。

## 群岛与航路带

群岛与航路带是中央内海体系中最适合容纳海上族群与混血文化的地方。

它们不属于单一国家，也不完全服从任何一块大陆的政治中心。更常见的情况是：

- 一个港口在名义上向某国纳税
- 它的船队却和另一地商会结盟
- 它的祭司向第三地的海神圣所朝圣
- 它的黑市与巡游学院停靠点保持密切联系

因此，这些群岛和海峡不仅是交通点，也是文明边界最松动的地方。

## 外海危险圈

中央内海之外，世界危险度明显上升。

这里不是单纯“没被开发的海”，而是文明普遍不愿深入、并且长期把其视为禁区或试炼地的危险外缘。可容纳：

- 永久风暴海
- 深海异常带
- 被遗弃的古代遗迹群
- 被门扉污染的岛链和裂海
- 魔界影响最容易渗透的边缘空间

按照当前世界观，**十二道门扉**不应平均撒在文明腹地，而更适合依附于这些边缘地带、深海、裂地和遗迹群。这样危险的方向才清晰：不是文明中心处处等量腐坏，而是边缘正在不断逼近中心。

## 这套地理在故事中的表现

读者最先感知到的，不会是“地图说明”，而会是以下差异：

- 港口里同时听见几种语言，看见几套不同风格的神像与建筑
- 精灵在林地中是主人，在港口中却可能是医者、书记员或异乡使者
- 矮人在山中拥有祖地和矿脉，在学院里却可能是最激进的炼成导师
- 边疆部族在腹地史书中被写成蛮人，但在遗迹与门扉前线却是最老练的守望者
- 同一个神明在不同族群口中有不同别称和仪式，但仍指向同一神格
- 巡游学院一到港，整座城市的秩序、价格、人流和谣言都会发生变化

## 暂不决定的内容

以下内容暂缓，不在本稿中细化：

- 各板块正式名称
- 各王国和各城邦的具体数量
- 主要族群的最终名单与分支谱系
- 巡游学院的正式名称、院系结构和内部人物
- 十二道门扉的精确位置
- 完整地图的气候带与比例尺

这些内容应在后续建立 `geo-主舞台板块`、`politics-制度总览`、`culture-主要文明板块` 后再继续下钻。

## 备注

本稿的核心目标，是把地理从“国界填色图”修正为“文明生态图”。

只要这份草稿成立，后续无论创建角色、势力还是故事起点，都能自然回答一个问题：这个人不仅来自某个地方，也来自某种文明层、某种迁徙路径与某种空间秩序。
