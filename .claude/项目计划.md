## 阶段四：正文写作

> 目标：按章节稳定输出。

### 写作工作流（每章）
1. 在 `05-PLOT/arc-当前卷.md` 中确认本章在大纲中的位置
2. 读取涉及角色的 `char-` 文件
3. 读取场景地点的 `geo-` 文件
4. 用 `tpl-chapter.md` 创建 `ch-XXX.md`
5. 填写 frontmatter（summary、pov、location、characters_present）
6. 写作正文
7. 更新 `06-CHAPTERS/_index.md` 的进度表格

## 与 Claude 协作备忘

### 快速提示词模板

**查找信息：**
```
请先读取 `00-INDEX/_MASTER-INDEX.md`，然后查找关于 [主题] 的设定
```

**创建新角色：**
```
请使用 `_TEMPLATES/tpl-character.md` 的模板，为我创建角色 [名字]，基本设定如下：[描述]
```

**写章节：**
```
请读取 arc-第X卷.md 了解剧情结构，再读取 char-[角色名].md，然后为我写 ch-[编号]，本章核心事件是：[描述]
```

**检查一致性：**
```
请读取所有 char- 开头文件的 frontmatter，检查 [角色A] 和 [角色B] 的关系是否有矛盾
```
