# 西幻世界观协作技能

辅助角色设计、设定修整与世界观扩展。核心原则：**先查后写，逻辑第一，趣味并重。**

## 触发条件

当用户要求以下任务时使用本技能：
- 创建或修改角色（char-）
- 创建或修改势力（fac-）
- 补全或修整世界观设定（magic-、religion-、culture-、geo-、hist-、politics-）
- 检查设定一致性
- 扩展现有设定

## 核心工作流：先查后写

**严格遵循以下顺序，不得跳过任何步骤。**

### 第一步：读取导航索引

必须先读取 `00-INDEX/_MASTER-INDEX.md`，获取全局视图和当前创作进度。根据任务涉及的领域，继续读取对应子域的 `_index.md`：

- 魔法相关 → `01-WORLD/magic/_index.md`
- 宗教相关 → `01-WORLD/religion/_index.md`
- 地理相关 → `01-WORLD/geography/_index.md`
- 历史相关 → `01-WORLD/history/_index.md`
- 种族/文化相关 → `01-WORLD/culture/_index.md`
- 政治相关 → `01-WORLD/politics/_index.md`

### 第二步：深入读取关联设定

根据任务需要，读取具体设定文件。**角色设计必读清单：**

| 如果角色涉及… | 必须读取 |
|--------------|---------|
| 魔导师身份 | `magic-魔导卡体系总览.md`、`magic-阶位造诣体系.md`，以及角色使用的卡牌类型文件 |
| 信仰/神选者 | 对应神明个档（`religion-神明-*.md`）+ `religion-神选者与神役者.md` |
| 特定种族 | 对应 `culture-种族名.md` |
| 特定地区 | 对应 `geo-*.md` |
| 历史背景 | `hist-纪元总览.md` 的相关纪元章节 |

**绝对不能凭记忆或猜测编写设定内容。每一条涉及已有设定的信息，都必须从文件中读取确认。**

### 第三步：检查逻辑一致性

创作前自查以下清单：

- [ ] 角色阶位与年龄/经历是否匹配（不朽阶需要漫长积累，年轻天才也有上限）
- [ ] 角色信仰与种族/地区信仰倾向是否一致（或有合理的偏离理由）
- [ ] 角色的卡组构筑是否符合魔导卡体系规则（加护卡不能叠魔法卡、幻兽卡不可转让等）
- [ ] 角色所属势力的立场、地理位置、文化背景是否自洽
- [ ] 新创内容是否违反"法则先在"的底层主轴
- [ ] 新创内容是否与已有的 17 位神明的权柄范围冲突
- [ ] 时间线是否与五大纪元框架吻合

### 第四步：创作并写入

使用 obsidian-markdown 技能的规范创建文件：
- 使用 `_TEMPLATES/` 下对应模板
- 完整填写 frontmatter（特别是 summary、related、关系字段）
- 所有交叉引用使用 `[[wikilink]]` 语法
- 单文件不超过 500 行

### 第五步：更新关联

- 更新对应的 `_index.md` 文件清单
- 更新关联文件的双向引用（如：新角色属于某势力 → 势力文件也要加该角色）
- 如有新术语，更新 `07-REFERENCES/glossary-术语表.md`

## 设计风格指南

### 西幻底色

借鉴但不照搬 D&D、《冰与火之歌》、《巫师》、Pathfinder 等经典西幻：

- **种族设计**：保留经典种族骨架（精灵长寿、矮人工匠、人类适应力），但赋予本世界独特的文化逻辑和魔导卡体系联结
- **命名风格**：偏向欧式音韵（拉丁/日耳曼/凯尔特混合风），避免纯日式或纯中式命名。神明命名格式为「职能之神 · 专有名字」
- **权力结构**：参考中世纪欧洲封建制但不拘泥，城邦共和、山城联盟、林地议会等多元政体并存
- **魔法质感**：本世界的魔法是"炼金术+符文学"的工业化产物，不是挥手念咒。保持卡牌、魔典、魔杖的实体感和仪式感

### 网文趣味

在西幻骨架上注入中文网文读者喜欢的元素：

- **成长爽感**：魔导师的阶位晋升、造诣突破、卡组升级要有明确的台阶感和突破爽感。12 阶 × 五色造诣提供了天然的升级快感框架
- **卡牌收集与构筑**：利用魔导卡体系的"卡组构筑"特性，制造类似 TCG/抽卡的趣味——稀有卡的获取、卡组搭配的策略性、关键时刻亮出底牌的燃感
- **势力博弈**：多方势力（学院、王国、神殿、商会、邪神教派）之间的信息差、算计和反转
- **伏笔与反转**：设计角色时预埋可以在后续揭示的秘密（身世、隐藏的卡牌、与神明的隐秘关系）
- **热血与燃点**：战斗场景要有"超阶对抗""绝境翻盘""底牌揭示"的设计空间
- **人物魅力**：角色要有鲜明的性格标签和记忆点，避免脸谱化但要让读者能一句话概括"XX 是个什么样的人"

### 平衡原则

- 不能为了爽感破坏魔法体系的内在逻辑（灵魂承载力是硬限制，不能随意突破）
- 不能为了反转破坏已建立的世界观规则（法则先在、神明起源等）
- 角色的强大必须有代价，天赋必须有限制，捷径必须有风险
- 邪神势力不是纯粹的"恶"，而是来自众生阴暗面的异化——保持灰度

## 角色设计专项规范

### 角色必备要素

每个重要角色至少明确以下内容：

1. **一句话定位**：用一句话说清"他是谁、他要什么"
2. **核心矛盾**：他内心最大的冲突或困境是什么
3. **与世界观的锚点**：他和魔导卡体系/神明体系/种族体系的具体连接点
4. **成长空间**：他在故事中可以从哪里走到哪里
5. **关系网**：他和其他已有角色/势力的关系

### 角色命名

- 使用 `07-REFERENCES/naming-规则.md` 的命名风格
- 不同种族/文化区域的命名应有可感知的差异
- 避免与已有名称（特别是 17 位神明名）过于相似

### 卡组设计

为魔导师角色设计卡组时：
- 明确阶位和主要造诣等级
- 列出核心卡牌（幻兽卡/精灵卡/魔法卡各几张）
- 说明战斗风格和战术偏好
- 标注是否拥有真理卡（极稀有，需要充分理由）
- 考虑灵魂承载力的限制——高阶卡越多，运作压力越大

## 设定修整专项规范

### 修整原则

- **最小改动**：只改需要改的，不顺手"优化"不相关的内容
- **向后兼容**：修改不能让已有的其他设定文件产生矛盾
- **双向更新**：改了 A 文件引用的 B 内容，B 文件也要同步更新
- **记录理由**：在 commit message 或文件备注中说明为什么改

### 新增设定的检查流程

1. 新概念是否与术语表中已有术语冲突？
2. 新规则是否与魔法体系六条硬限制冲突？（见 `magic-魔导卡体系总览.md` 第六节）
3. 新历史事件是否与五大纪元时间线矛盾？
4. 新神明/权柄是否与已有 17 位神明的法则领域重叠？
5. 新地点是否与已有地理框架的文明单元逻辑一致？

## 世界观硬限制清单

以下规则不可违反，任何创作都必须遵守：

1. **法则先在**：法则先于神明存在，神明不是法则的创造者
2. **无创世神**：没有人格化创世者，混沌不是神
3. **信仰不造法则**：信仰可强化/塑形神格，但不能凭空制造不存在的法则
4. **邪神内源**：邪神源于众生阴暗面的催化，不是纯粹外来入侵
5. **灵魂承载力硬限制**：不可通过外部手段临时扩充
6. **加护卡不叠魔法卡**：只能叠加在召唤物/武装上
7. **幻兽卡不可转让**：强行破解导致焚毁或法则反噬
8. **真红不可复制**：真红造诣无法被公式化复制
9. **降临协议**：正神正常情况下不得直接降临主世界
10. **神明命名格式**：「职能之神 · 专有名字」，不能只用称号，避免中二
